# AT:R55  (2026-07-12)

A data-integrity investigation into the 12-agent Room that snowballed into closing an
entire in-repo sub-workspace. Confirmed the News and Social Media analysts run on zero
real data, filed the fix as two CRs, then — at Saiful's direction — reviewed and closed
`Silent_Scout/` entirely, converting everything of value into 8 more CRs.

## What happened

### The check that started it
Saiful asked whether Room agents get real live feeds, "specially the news and social
media agents." Investigation (`room_runner.py::_profile_for_ticker()`, lines 200-287)
confirmed both run on hardcoded strings / `rng`-seeded placeholders, despite their base
prompts claiming real feeds (Reuters/Bloomberg/FT; Reddit/Twitter/StockTwits/Discord).
The real yfinance news fetcher that already exists (`market_data.py` →
`GET /v1/sim/news/{ticker}`) is completely disconnected from the agent pipeline — it
only serves the mobile Ticker Detail screen.

### CR023 + CR024 — the fix, docs-only (`3e38b58`)
Found **CR007** (filed AT:G1, 2026-07-09) had already done the exact provider research
needed — recommended Alpha Vantage NEWS_SENTIMENT ($49.99/mo, connector already coded
in the mounted TradingAgents framework) and LunarCrush (~$30-100/mo social sentiment
aggregator). Built CR023 (news) and CR024 (social) directly on CR007's findings rather
than re-researching from scratch; re-confirmed both providers' pricing live. Corrected
`Silent_Scout/05_agent_alignment/`'s Gap 5 framing from "Structural" (permanent) to
"Scheduled" (proposed, not yet built).

### Silent_Scout-wide audit (2 background agents, report only)
Saiful then asked for a full review of every Silent_Scout track given the shift to GTM
mode. Two parallel audits (00-04+07_voice; 08+10-18) surfaced:
- **GB10 capacity conflict** — the LoRA research box (`192.168.20.74`) turned out to be
  the *exact same host* running production vLLM inference for all 13 live agents. Never
  addressed in 9 weeks of "active research" — likely why that track has zero execution
  artifacts.
- **`12_watchlist_badge` mismarked "DELIVERED"** — never shipped; backend still
  hardcodes `day_change_pct=None`.
- **Broken safety-floor eval** (`mandate_compliance_eval.py`) — constructs
  `ProposedTrade` with kwargs that no longer exist post-schema-refactor; the "100%
  block on 500 adversarial cases" claim is currently unverifiable.
- **A fabricated "Risk Agent"** cited as a data owner in 3 separate designs (price
  alerts, sector allocation, trailing stop) — no such agent exists in the 13-agent
  roster.
- `08_holding_detail` stale in the opposite direction (undersells shipped work); dead
  `~/.claude/plans/` links; `11_earnings_dividends` overclaimed (only earnings shipped,
  not dividends); `07_voice` 100% pre-benchmark despite having no external blocker.

## Gotchas learned
- **Check the CR register before researching** — CR007 already covered the exact
  provider research this session needed; reusing it instead of duplicating saved a full
  research pass. Always check `cr_list.md` for adjacent-topic CRs before spinning up
  fresh research.
- **"Shipped/delivered" claims in research docs need verification against current
  code, not the doc's own word** — found two false-positive "delivered" claims in
  Silent_Scout alone (`09_per_ticker_news`, `11_earnings_dividends`) plus one doc that
  understated shipped work in the opposite direction (`08_holding_detail`).
- **GB10 (`192.168.20.74`) is the production vLLM host, not a spare research box** —
  any future GPU-hungry research on that IP needs an explicit capacity/scheduling
  answer first; this was silently blocking the LoRA track the whole time.
- **A "Risk Agent"/"Risk Analyst" doesn't exist** in the 13-agent roster
  (`backend/app/schemas/agents.py`) — any design doc (old or new) that cites one should
  route through Portfolio Manager or `safety_floor.py` instead.
