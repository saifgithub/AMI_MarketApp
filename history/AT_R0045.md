# AT:R45 (2026-06-02)

## What shipped

### Alpaca paper trading OAuth integration (`4bdcd54`)

The big feature this session. Paper trading is treated as simulation (no real money), so it's in scope. The full stack shipped in one commit:

**Backend:**
- Migration `a1b2c3d40012` — adds `alpaca_access_token`, `alpaca_refresh_token`, `alpaca_linked_at` to `users` table.
- `backend/app/services/alpaca_service.py` — OAuth code exchange (`exchange_code`), Alpaca paper API proxy (`get_account`, `get_positions`), and `snapshot_text()` which formats a compact portfolio block for agent prompt injection.
- `backend/app/api/alpaca.py` — 5 routes: `POST /v1/alpaca/link`, `DELETE /v1/alpaca/unlink`, `GET /v1/alpaca/status`, `GET /v1/alpaca/portfolio`, `GET /v1/alpaca/positions`. All require a claimed (non-anonymous) user.
- `backend/app/core/config.py` — 4 new env vars: `ALPACA_CLIENT_ID`, `ALPACA_CLIENT_SECRET`, `ALPACA_PAPER_BASE_URL`, `ALPACA_OAUTH_TOKEN_URL`, `ALPACA_REDIRECT_URI`.
- `backend/app/services/agent_prompts.py` — `build_agent_prompt` gained `alpaca_snapshot: str | None` param. When set, injected after user overlay, before safety floor.
- `backend/app/services/agent_runner.py` — fetches Alpaca snapshot from DB at 1-on-1 start; passes to `build_agent_prompt`.
- `backend/app/services/room_runner.py` — fetches snapshot once at `run()` start; stored in `_RoomContext.alpaca_snapshot`; threaded into every `_speak_one_agent` and `_stream_pm_narration` call.
- `backend/app/services/room_prompts.py` — `build_room_messages` gained `alpaca_snapshot` param, forwards to `build_agent_prompt`.
- `backend/tests/unit/test_alpaca.py` — 20 new tests. Full suite: **532 passed**.

**Mobile:**
- `webview_flutter ^4.10.0` added to pubspec (resolved to 4.13.1).
- `mobile/lib/models/alpaca.dart` — `AlpacaStatus`, `AlpacaPortfolio`, `AlpacaPosition` models.
- `mobile/lib/state/alpaca_providers.dart` — `alpacaStatusProvider`, `alpacaPortfolioProvider`, `alpacaPositionsProvider` (all `FutureProvider.autoDispose`).
- `mobile/lib/services/api/api_client.dart` — 5 new methods: `alpacaStatus`, `alpacaLink`, `alpacaUnlink`, `alpacaPortfolio`, `alpacaPositions`.
- `mobile/lib/screens/settings/alpaca_connect_screen.dart` — embedded WebView OAuth. `NavigationDelegate` intercepts `amitrade://alpaca/callback` before OS. `ALPACA_CLIENT_ID` via `--dart-define`. Error banner on access_denied.
- `mobile/lib/screens/settings/settings_screen.dart` — new **CONNECTED ACCOUNTS** section with `_AlpacaSection` / `_AlpacaRow` (green dot = linked, Connect/Disconnect button; hidden for anonymous users).
- `mobile/lib/screens/sim/portfolio_screen.dart` — new `_AlpacaPortfolioSection` below sim trades: cash/equity/buying-power summary card + position tiles. Hidden when unlinked. Pull-to-refresh invalidates Alpaca providers.
