# AT:R42  (2026-05-30)

TickerDetail Bundles 4+5 — News + Earnings.

## What shipped

**Backend:**
- `GET /v1/sim/news/{ticker}?limit=5` — 5-min cache, yfinance-backed, returns `[{title, link, publisher, pub_date}]`
- `GET /v1/sim/earnings/{ticker}` — 6h cache, returns `{ticker, next_earnings_date, estimated_eps, fiscal_quarter}` with 90-day forward window
- `NewsItem` + `EarningsInfo` NamedTuples added to `market_data.py`
- `news()` + `earnings()` protocol methods wired across all 4 providers: `YfinanceProvider` (real yfinance data), `MockWalkProvider`/`Yahoo` (empty stubs), `CachingProvider` (separate TTL dicts for news/earnings), `FallbackProvider`
- `SimEngine.current_news()` + `current_earnings()` follow `current_history()`'s never-raises contract
- New: `url_launcher` dep added to mobile pubspec

**Mobile:**
- `SimNewsArticle` + `SimNews` + `SimEarnings` models in `mobile/lib/models/sim.dart`
- `tickerNewsProvider` + `tickerEarningsProvider` FutureProviders added to `ticker_history_provider.dart`
- `simNews()` + `simEarnings()` API client methods
- TickerDetail: `_EarningsPill` (amber pill, "Q3 · Jul 25 · est. EPS $2.04", 90-day cutoff, hide-on-empty) between Actions and the news section
- TickerDetail: `_NewsSection` (5 `_NewsRow` tiles, publisher + relative-time sub-label, tap opens Safari via `LaunchMode.externalApplication`)
- Both sections hide when data is empty (no placeholder)
- 10 new l10n keys

**Tests:** 500 → 512 (+12 in `test_sim_news_earnings.py` — route validation, mock stubs, cache TTL behaviour)

## Deploy

Promoted to Alpha — tag `alpha-2026-05-30-1`.

## Gotchas for next session

yfinance ≥0.2 changed the news article shape from flat dicts to `{content: {...}}` nested objects. The initial implementation didn't handle the nesting — broke immediately on Alpha. Fixed in AT:R43.
