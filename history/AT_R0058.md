## Gotchas learned
- **Audit lanes must open the moment a DEF/CR ships, not after the fact** —
  this session had to correct the gap twice from two different directions:
  once because Saiful caught CR023/CR024/DEF051 shipping without lanes, once
  self-caught (DEF049/050's lane files were COMPLETE but `INDEX.md` never
  updated to match). Self-applying that lesson to DEF052-055 (lanes opened
  proactively, same commit or the next) worked — but CR034/DEF056 still slipped
  through, because they came from a parallel window under the same session
  tag that didn't know the convention. **A `/handover` (or any session-scope
  audit) must diff against the last wrap commit
  (`git log <last-wrap-sha>..HEAD`), not rely on the current conversation's
  own memory of what shipped** — this project has a standing pattern of
  parallel windows/sessions committing under one session tag (previously
  AT:R48/R50, track G, track U; this session, an untracked parallel window
  doing real feature work). `sh audit/handshake/watcher.sh state` plus a
  fresh `ls audit/handshake/cr/` diffed against `def_list.md`/`cr_list.md` is
  the reliable way to find what's missing a lane — never assume "I remember
  everything that shipped."
- **`math.isfinite()` guards are now load-bearing house style for any code
  ingesting raw yfinance numeric fields** — NaN is yfinance's real
  missing-value sentinel (not just an absent dict key), and an unguarded
  `round()` on NaN raises `ValueError`. DEF052's F1 (MAJOR) and DEF053's two
  OUT-OF-SCOPE observations were the same underlying bug class in three
  different call sites this session alone — worth grepping for on sight in
  any future fundamentals/technicals-adjacent work, not just reacting to it
  per-incident.
- **`pytest`/`flutter analyze` need their actual environment activated before
  a "did it really pass" re-check means anything** — running `pytest` without
  `source backend/.venv/bin/activate` first silently picks up a bare
  Homebrew Python 3.14 with no project deps installed (`ModuleNotFoundError:
  structlog`), which looks like 56 collection errors, not "56 passing tests
  before this session's changes." Always activate the venv before trusting a
  red result as a real regression.
