## Gotchas learned

- **A plain `flutter build apk --release` bakes NO dart-defines** → every
  backend mode resolves empty → the APK reaches no backend at all. The `+36`
  APK had this bug. MUST build via `scripts/install_android.sh`'s defines path
  (or replicate `--dart-define=ALLOW_BACKEND_SWITCH=true --dart-define=AMI_API_URL_ALPHA=…`).
  `+37` fixed. TestFlight already bakes them via `build_testflight.sh`.
- **DEF044 key derives from `SECRET_KEY`** — a promotion is only idempotent if
  `infra/alpha.env`'s SECRET_KEY matches melehost's. Verified by hash before
  scp (they matched; no rotation). If SECRET_KEY ever rotates, encrypted
  Alpaca rows won't decrypt (they fall back to returning ciphertext).
- **`EncryptedString` re-encrypt trick**: reassigning the same ORM value is a
  no-op (change detection) — use `flag_modified()` to force encrypt-on-write.
- vLLM prefix caching is real but under-used (18.5%) — prompt reordering is the
  highest-leverage cache fix, provider-agnostic (CR017 §5 step 0).
- Migration promote of DEF044 was clean (EncryptedString keeps the column
  VARCHAR — no schema change, `alembic upgrade head` a no-op). Contrast R52's
  DuplicateTable footgun.
