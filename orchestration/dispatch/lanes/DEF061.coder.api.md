## Stated build-lane decisions

- **UNKNOWN (not in the classified universe) → PERMITTED with a disclosure, NOT blocked** — mirrors halal G3. Blocking-on-unknown would reject every unclassified name (the DEF059 inversion trap). Asserted explicitly (`test_unknown_is_permitted_with_disclosure_not_blocked`).
- **None / stale / disabled / seed universe → paused (loud degrade, UNAVAILABLE is blocking)** — never a silent empty set that would permit every name.
- **Parent set reused, never re-fetched:** the ~503 S&P constituents come from `sharia_universe_snapshots.parent` (CR075). So a live classify pass depends on the Sharia snapshot being seeded first; absence raises → loud pause, never an empty classification.
- **Read path opens no socket** (CR075 lesson): the provider fetcher is a local DB read; the ~500 yfinance calls live only in the daily refresh.
- **Floor `_CLASSIFIED_MIN_ROWS = 400`:** a classify pass that tags fewer than this of the parent set RAISES (throttled/broken run) rather than storing a short universe that would un-enforce the filter for most names.
- **esg is DERIVED, buckets are stored:** only fossil/sin/defense are persisted; esg = their union, so the three reviewable buckets stay the single source of truth.
- **`custom_constraints` NOT touched** (separate `coder.room` lane, per the coordinator). `esg_lite` built as a curated proxy per the founder's 2026-07-25 ruling.
