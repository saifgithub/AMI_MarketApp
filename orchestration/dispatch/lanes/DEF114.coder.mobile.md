## Round 1

Followed D1-D6 as settled in `DEF114.assign.md` — did not re-open any of them.

1. **D1 (single-pass unescape).** Replaced the two-`replaceAll` pair at all three call sites
   (`agent_token` in `parseRoomSseEvent`, `streamBriefMessage`, `streamOneOnOneMessage`) with one
   shared `unescapeSseText()` (top-level, `@visibleForTesting`), a left-to-right scan that consumes
   `\\`/`\n` escape pairs atomically. Did **not** pin the shipped order or the swapped order as a
   test — both are the bug per the Architect's measurement.
   13-case round-trip corpus in `api_client_sse_unescape_test.dart`, asserted against the real
   backend encode (`chunk.replaceAll(r'\', r'\\').replaceAll('\n', r'\n')`, transcribed verbatim,
   not re-derived). All 13 pass.
2. **D2 (client-only).** Backend untouched — `git diff main...HEAD -- backend/` is empty. Flagged
   below per FLAG 1, not acted on.
3. **D3 (per-chunk decoding safe).** Verified by inspection: `brief.py`/`one_on_one.py` escape each
   chunk independently before it's written to the SSE frame, so no escape sequence spans a chunk
   boundary. Did not find a sender that escapes across a boundary — nothing to flag here.
4. **D4 (inject the http client).** `ApiClient` now takes an optional `httpClient` (defaults to
   `http.Client()`); all three inline `http.Client()` constructions (`:301`, `:418`, `:668` in the
   pre-fix file) now route through the one shared `_httpClient` field. Per-call `client.close()` in
   each stream's `finally` block was removed — it can't survive being shared across calls; the
   client's lifetime is now the `ApiClient`'s, not the individual stream call's. No other
   restructuring of `ApiClient` — did not need to touch the Dio side, auth interceptor, or anything
   else (FLAG 3 didn't fire).
5. **D5 (demonstrate both mutations red, then revert).** Pasted below.
6. **D6 (cover the other two surfaces).** `streamBriefMessage` and `streamOneOnOneMessage` both get
   a done-terminates test in `api_client_stream_termination_test.dart`, same as Room — all three
   surfaces covered, not just the one acceptance criterion 5 requires.
