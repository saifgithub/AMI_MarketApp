## The row understates this. It is not a coverage gap — it is live corruption.

The row describes M1 (the auditor's swapped-order mutation staying green) as untested code. **The
Architect ran the actual round-trip in Dart against the real backend escape.** The shipped decode is
**wrong, and so is the swapped order** — the mutation is not fixable by pinning the current
behaviour, because the current behaviour is the bug.

Backend encode — identical in all three senders (`room.py:213` and `:236`,
`one_on_one.py:115`, `brief.py:115`):

```python
safe = chunk.replace("\\", "\\\\").replace("\n", "\\n")
```

Client decode — identical in all three consumers (`api_client.dart:136-137`, `:326`, `:446`):

```dart
.replaceAll(r'\n', '\n').replaceAll(r'\\', r'\')
```

Two sequential `replaceAll`s **cannot** invert that encode in either order, because the first pass
matches across an escape boundary. Measured, real Dart, current `main`:

| Analyst text | Shipped order | Swapped order (M1) |
|---|---|---|
| `line one⏎line two` | OK | OK |
| `the token \n means newline` | **CORRUPTED** → `\` + newline | **CORRUPTED** → newline |
| `C:\next\report` | **CORRUPTED** → `C:\` + newline + `ext\report` | **CORRUPTED** |
| `a\\b`, `ends with \` | OK | OK |

**The trigger is a backslash immediately followed by `n`.** Rare in equity prose, not absent —
a path, a regex, or an agent explaining what `\n` means. Silent when it fires: the transcript just
renders a stray line break.

**It is on all three streamed surfaces**: `parseRoomSseEvent`'s `agent_token` (every analyst's text
in every Room run), `streamBriefMessage` (Brief Your Agent), `streamOneOnOneMessage` (1-on-1 chat).

## Architect decisions — settled, do not re-open

**D1 — Replace the two `replaceAll`s with ONE single-pass unescape, in ONE shared helper, used by
all three call sites.** Scan left to right; on `\`, consume the next char: `\`→`\`, `n`→newline,
anything else→emit both as-is. Do **not** pin the current order in a test — that enshrines the bug.

The Architect verified this exact algorithm against the unchanged backend encode on 13 cases
(plain newlines, literal `\n` in prose, Windows paths, `a\\b`, trailing backslash, backslash-then-
newline, `\\n`, repeated newlines, unicode + emoji, quotes/tabs, empty, lone backslash, `\n\n`):
**all 13 round-trip exactly.** Reproduce that table as your test corpus and add to it.

**D2 — CLIENT-ONLY. Do NOT change the backend escape.** The manual pre-escape in `room.py` is
strictly redundant (`json.dumps` already escapes), and deleting it is tempting. **Measured: don't.**
Dropping it while already-shipped clients still run the old unescape *regresses* `a\\b`, which
round-trips correctly today, and buys nothing the client-side fix doesn't already give. A client-only
single-pass decode is correct against the wire format as it stands, needs no coordinated release, and
leaves old clients exactly as they are — no worse. Note the redundancy as future cleanup in your
hand-off; do not act on it.

**D3 — Per-chunk decoding is safe; do NOT build a stateful cross-chunk decoder.** `brief.py` and
`one_on_one.py` escape **each chunk independently and completely**, so an escape sequence can never
span a chunk boundary: a chunk ending in `\` is already `\\` inside that chunk. Verify this holds and
say so; if you find a sender that escapes across a boundary, **stop and flag it** rather than
inventing a stateful decoder.

**D4 — Inject the HTTP client so M2 becomes testable.** M2 (making `done` no longer terminate the
generator, suite stayed green) is the "a Room run that never finishes" failure, and it is untestable
while `streamRoom` builds `http.Client()` inline at `:668`. Add a constructor-injected client
defaulting to `http.Client()`. There are three inline sites (`:301`, `:418`, `:668`) — route all
three through the injected instance so Brief and 1-on-1 become testable too, but **do not otherwise
restructure `ApiClient`**; it is large and shared.

**D5 — Both auditor mutations demonstrated failing, then reverted.** M1: swap the unescape order →
must go red. M2: make `done` not terminate the generator → must go red. Paste both failure outputs.
A guard nobody has seen fail is a guard nobody knows works.

**D6 — Test the two other surfaces too.** `streamBriefMessage` and `streamOneOnOneMessage` carry the
same helper and the same `done`-terminates contract. Cover them, or state explicitly why one cannot be.
