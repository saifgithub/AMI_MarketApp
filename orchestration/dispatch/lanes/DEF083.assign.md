## Round 2 — content review verdict: **CHANGES REQUIRED** (Architect, 2026-07-22)

Round 1 is **accepted on substance**. I verified `276` against its live `options` array: the trap is
index 3 (*"Trust the verdict — AMI's twelve agents would have caught any errors"*), the old copy said
"the first one" (index 0, *"Reject the verdict outright"*) — wrong — and the rewording now names the
answer by its own text, so a future shuffle cannot re-break it. The guard widening and the
`shuffle_quiz_answers.py` mirror are both correct. Revert-test evidence accepted.

**One finding, and it must be fixed before this lands.**

The bare-ordinal branch is too loose:

```
\bthe\s+(?:first|second|third|fourth|fifth|last)\s*[—–-]
```

`\s*` permits zero whitespace and the class includes the ASCII hyphen, so it matches **hyphenated
compound adjectives**. You resolved the two hits it produced by **de-hyphenating the prose**:

- `188` — "the second-derivative ratio" → "the second derivative ratio"
- `249` — "the second-derivative readings" → "the second derivative readings"

That is backwards. The guard exists to serve the corpus, not the other way round — and
"second-derivative" as a compound adjective was correct English, so this edit slightly degrades two
lessons to satisfy a regex. Nothing in the defect asked for it, and a reader would see a wording
change with no reason behind it.

**Do instead:**

1. Tighten the branch to require real whitespace and drop the ASCII hyphen:
   `\bthe\s+(?:first|second|third|fourth|fifth|last)\s+[—–]`
   I tested this: it still catches every genuine case (`the last — 'the crowd has new
   information'`, `the first — 'AMI has approved'`, `the first one: '…'`, `the first answer`,
   `the third choice`) and stops matching `the second-derivative ratio`.
2. **Restore the hyphens** in `188` and `249`.
3. Mirror the tightened branch into `scripts/shuffle_quiz_answers.py` — it currently carries the
   loose version too, so the blind spot is duplicated.
4. Re-run the revert-test and paste both exit codes again.

Note the same compound-adjective pattern also appears in lesson *prose* (`207` "the second-best",
`266` "the second-victim"). Those did not trip the guard because it scans quiz explanations only —
but they are exactly why the branch must not match hyphenated compounds. Leave them alone.
