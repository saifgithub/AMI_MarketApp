widening it. The pre-fix RED run (below) surfaced **36 offenders across 31 lessons**. All 31
were reworded. Breakdown:

  `019` q1+q2, `045` q1, `049` q3, `103` q2, `110` q1+q2, `111` q1, `200` q1, `276` q1, `277` q1.
  (`276`/`277` — the "don't over-trust AMI" lessons — now name 'twelve agents would have caught
  it' and 'AMI has approved' respectively, the actual traps.)
- **13 positionally-fragile** (defect §"do NOT silently fix") — reworded by content, no index
  guessed: `013 014 059 075 077 101 201`(q2) `202 254 274 275 279`, plus `139` q0 option[3]
  ('second one' → 'the second cross'). `101` substance left intact (CR060-refuted) — positional

- **10 extra, caught by the widened branch** — same class, same fix (name by content):
  `017 100 108 109 206 260 298` (`298` q1 is an *option* surface: "The second —"/"The first —"
  → "The second adviser —"/"The first adviser —", which reads better and no longer trips the

- **2 benign hyphen false-positives** of the bare-ordinal branch `the <ordinal>[—–-]`:
  `188` and `249` matched "the **second-**derivative ratio" (a math term, not an option ref).
  Resolved by de-hyphenating to "the second derivative". No meaning change.

Every fix touches explanation/option prose only — `question`, `options` order, and `answer`
