### 1. Sector aggregation (pure)
`allocate_by_sector(holdings, quotes) -> dict[str, float]` — sector → weight (0.0–1.0). Sum
`quantity × current_price` per sector, normalise by total portfolio value. Empty portfolio → `{}`.
`None`/missing sector → `"Other"` bucket, logged, never raises (the `fundamentals.py` never-raises
pattern). Pure function, unit-tested in isolation.

### 2. Sector resolution — ZERO NETWORK ON THE REQUEST PATH (CR075/DEF089 rule — non-negotiable, D-5)
The endpoint AND the safety-floor check both need a ticker→GICS-sector map. Resolve it from the
**pre-populated `classification_universe` snapshot**, NEVER a live `yf.Ticker().info` fetch on the
request path (the CR075 lesson: the first trade after a restart must not pay for a socket).
- **First check whether the snapshot already persists the raw sector.** `classification_universe.py`
  fetches `info["sector"]` to derive fossil/sin — if it already stores the raw sector tag, just READ
  it (no schema change). If it only stores the derived sets, **extend the snapshot to carry the
  per-ticker GICS sector** (new column or add to the stored payload) + a migration; populate it in the
  existing `run_classification_refresh_tick`. Unknown/missing stored sector → `"Other"` + disclosure,
  never a request-path fetch. **Degrade loudly** if a refresh classifies < a sane floor of the parent
  set (mirror the existing `_PARENT_MIN_ROWS`-style guard).

### 3. The endpoint
`GET /v1/portfolio/sector-allocation` (AUTHENTICATED, user's own — `_own` guard like `sim.py`) →
`{allocation: {sector: weight}, total_value, compliance: {max_sector, max_allowed, compliant}}`.
`max_allowed` reads the mandate's sector-concentration tolerance (**default 0.40**, per
`lifecycle.md:120`) — read it from the user's mandate, do not hard-code.

### 4. THE ACTUAL GAP — enforcement in `check_mandate_compliance()`
Wire `allocate_by_sector()` into the deterministic safety floor **alongside** the existing single-name
concentration block: a proposed BUY that would push any sector over the mandate's sector cap is
flagged/blocked with `blocked_by="compliance"`, the SAME shape single-name concentration uses today.
The single-name block must stay byte-unchanged except for the added sector call. **This is the gap the
CR closes — it needs a regression test that FAILS without the fix** (DEF039/DEF049 adversarial
pattern): a portfolio one trade away from breaching the sector cap must be blocked; delete the new
check and that test must go red.
