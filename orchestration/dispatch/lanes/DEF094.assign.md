## Why it matters

A successful trade currently carries **nothing** that distinguishes a screened PASS from an
unscreened UNKNOWN. Confirmed against the deployed `openapi.json`: `ShariaVerdict` appears in **no
response schema across all 102 live paths**, and `AAPL` (pass) and `ASML` (unknown) return
byte-identical bodies.

G3's ruling is *unknown is permitted, **with the disclosure attached***. The permission crosses the
wire today. The disclosure does not. That is a silent pass on an observance decision — the precise
failure CR069 exists to prevent.

`coder.mobile` refused the tempting workaround — inferring state from `passed: true` — because it is
*"a two-state answer to a four-state question and would mark every unscreened ticker as
screened-and-cleared."* Correct. Do not reintroduce it from the backend side by collapsing the four
states into a boolean on the way out.

**Four states, all four on the wire:** PASS / SCREENED_OUT / UNKNOWN / UNAVAILABLE. `is_blocking` =
SCREENED_OUT | UNAVAILABLE. UNKNOWN permits **and** discloses.

## How it survived — read this before writing the test

This is DEF089/DEF092's lesson pointed at a new surface. CR069-BE's go-live evidence verified the
resolver **inside the container** (`compliant=216 parent=503`, correct verdicts) and never once
checked that a *client* receives the verdict. **Verifying the component is not verifying the
contract.** Third time in one session that a check proved less than it appeared to: curl instead of
the shipping client (DEF092), one of two sources fetched (DEF089), now the resolver instead of the
response.

So the test that matters asserts the **response body**, not the resolver.

## Tests

1. A response-level test for each of the four states, asserting the serialized key is present and
   carries the right state — including on an **accepted** trade, which is where it is dark today.
2. A regression test that `AAPL` and `ASML` responses are **not** byte-identical.
3. Confirm `ShariaVerdict` now appears in the generated OpenAPI response schema — the deployed spec
   is the artefact `coder.mobile` mirrors by hand.

**Self-test:** `cd backend && .venv/bin/python -m pytest tests/unit/ -q -k "sim or sharia or compliance"`
then the full `tests/unit/ -q`.
