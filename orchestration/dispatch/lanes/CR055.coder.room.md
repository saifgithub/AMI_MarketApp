sourced from the sim engine, UNCONDITIONALLY — closing the SCHD phantom-holdings
hallucination (a new user's Trader refused to buy, citing a fabricated 10–15% holding).

## Note on the assign (truth, not confirmation)

- The assign's HOT-FILES line-numbers were from `main`'s tree; the worktree was 19
  commits behind so they were shifted, but every referenced site was located and is
  correct in substance.
- The assign (and CR spec) say `sim.list_trades(user_id, status=OPEN)`. The real API
  uses a **string literal** `TradeStatus = Literal["open", ...]`, not an enum member
  `OPEN` — used `status="open"`.

  NOT grep in the prompt files today (reworded/removed since 2026-07-21). The assign
  already flagged this caveat; confirmed. The fix does not depend on it — agents are
  blind on holdings regardless — so no comment references that string.
