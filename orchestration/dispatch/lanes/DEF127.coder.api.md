## The process mistake, since it is the most useful thing here

The first mutation matrix ran **before the fix was committed**, and each mutation was reverted
with `git checkout -- <path>` — which reverts to the *committed* state, i.e. pre-fix. It
deleted the fix from all three files mid-matrix and left the untracked `sse.py` mutated. Every
number after M1 was contaminated. Re-applied, committed, re-ran clean.

**Never revert a mutation with `git checkout` while the fix is uncommitted.**
