# CR075 — coder.api lane

**Item:** persist the sourced Sharia universe in a table, refresh it daily in a background task, and resolve every request from the stored row. Takes the network fetch off the request path (a restart reads the row, never a socket) and turns a source outage from DEF093's every-halal-trade block into an ageing-but-served list disclosing its held as-of.

**Spec:** `docs/forward_planning/CR075_persist_the_sharia_universe/CR075_persist_the_sharia_universe.md` (§What, §Acceptance). **Assign:** `orchestration/dispatch/lanes/CR075.assign.md`.

## Stated decisions

- **Latest-vs-history: APPEND-ONLY.** One row per successful fetch; read = latest row for the standard by `fetched_at`. Rationale: the CR's defensibility argument ("which names did AMI treat as compliant on day X → a row answers it") needs history, and `fetched_at` advancing across rows while `as_of` holds is exactly what makes a frozen parent mirror visible (A4). Storage is negligible (~1 row/day, two lists of a few hundred tickers).
- **Retention: unbounded for now** (matches `llm_audit`). One row/day ≈ 365/year — a retention sweep can be added later if volume ever warrants; not in this CR.
- **Hold-window: 30 days** (`sharia_hold_window_days`, new setting), deliberately longer than the 7-day `sharia_staleness_days`. Rationale: the 7-day window was chosen when the fetch sat on the request path and a failure meant an immediate hard block (DEF093 blast radius). With the list persisted, a source outage no longer blocks — the held list is served with its held as-of — so a recorded, attributable row is a lower risk to serve stale-ish. 30 days keeps every served list inside one quarterly SPUS rebalance cycle while still pausing loudly (UNAVAILABLE) if the source has been effectively dead for a month. This is the "much longer runway before the pause fires" the CR buys, named rather than inherited.
- **`sharia_staleness_days` (7) kept live**, repurposed as the *source-freshness* signal: after a successful fetch, `sharia_source_lagging` warns if the source's own file is already older than 7 days. Distinct layer from the reader's hold window.
