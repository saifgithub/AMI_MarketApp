## MINOR — the `to_thread` exemption was inverted

`_to_thread_wrapped_call_ids` **deleted entirely**, not patched. The shape it exempted —
`asyncio.to_thread(leaf(x))` — is *never* correct: the leaf is called inline (blocking the loop)
and then its result is handed to `to_thread`, which `TypeError`s. The correct shape passes the leaf
**by reference**, where it is an `ast.Name`/`ast.Attribute` argument and never an `ast.Call`, so it
is invisible to the walk anyway. The exemption could only ever launder a bug.

**Mutation-verified (the auditor's probe P-E):** `await asyncio.to_thread(sim.current_quote(ticker))`
was **green** in round 1; it is now red in **both** tests. Reverted, green.
