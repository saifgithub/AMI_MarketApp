## The defect, located by NAME (line numbers drift — do not trust the ones below)

`backend/app/services/room_runner.py`, inside `async def run(`:

```python
sim_block = _build_sim_holdings_block(user_id, ticker)          # ~:1995, NOT awaited
...
sector_holdings, sector_marks, sector_map, sector_weights = (
    _build_room_sector_context(user_id)                          # ~:2001, NOT awaited
)

profile = await asyncio.to_thread(_profile_for_ticker, ticker,   # ~:2004, awaited CORRECTLY
```

Both builders reach the network:

- `_build_sim_holdings_block` → `sim.total_value(user_id)` **and** `sim.current_marks(list(agg))`
- `_build_room_sector_context` → `sim.current_marks([h.ticker for h in holdings])`
- `SimEngine.current_marks` → `_marks_with_quotes` → `ThreadPoolExecutor(...)` + `pool.map(self.current_quote, unique)` — a real yfinance fan-out, once per holding, **every Room convene**.

Because they are called without `to_thread`, that whole fan-out runs on the loop thread. Every other
Room stream, SSE heartbeat and request served by that worker waits for it.

## Acceptance

1. **Both call sites wrapped** — `await asyncio.to_thread(...)`, in `async def run()`. Do not change
   what either builder returns or the order the prompt is assembled in.
2. **`_WAIVED_CALL_CHAIN_NAMES` emptied** in `backend/tests/unit/test_no_blocking_io_in_async_routes.py` —
   delete BOTH `_build_room_sector_context` and `_build_sim_holdings_block`.
3. **`_DEF120_KNOWN_BLOCKING_PAIRS` shrunk to `set()`.** `test_waived_chains_still_pin_the_known_offender_set`
   asserts in BOTH directions: a pair that stops blocking while still pinned fails it. So 1–3 land
   together or the suite is red — that is deliberate, and it is the check that proves the fix is real
   rather than a waiver moved around.
4. **Mutation proof, both sites, reported with the failing test names.** Un-wrap one call site at a
   time and show the guard goes RED; restore and show green. A fix whose guard stays green when you
   break it is not a fix.
5. **Demonstrate the loop is actually free.** This has never been measured — all four DEF120 rounds
   reasoned statically. Add an async test that monkeypatches the builder's leaf to sleep and asserts
   the loop stays responsive across the call (e.g. a concurrent task keeps ticking, or the total
   elapsed time is bounded well under the sum of two serialised sleeps). Assert on **loop
   responsiveness**, not on wall-clock alone — a timing-only test flakes on a loaded machine.
6. **Full suite green from the repo root**, foreground: `./backend/.venv/bin/python -m pytest backend/tests/unit/ -q`.
   Baseline on `main` is **1404**. Report the number you actually saw.
