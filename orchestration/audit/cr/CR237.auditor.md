## Foreign-pass dispositions (foreign/CR237.r1, 5 findings)

Read via `git show foreign/CR237.r1:...`, each re-verified at file:line by me. Counts for
`foreign_trail.md`: **3 real, 1 real-but-narrow (downgraded), 1 real-but-pre-existing**.

### MAJOR-1 (foreign #1 — REAL). A successful retry wipes `sheet_state` / `reference_price` / `next_convene_delta` off the persisted verdict

`run()` stamps all three onto every completed run's verdict post-loop
(`room_runner.py:6638-6643`) — including the original outage PASS, so the persisted row
carries them. `retry_cio_step` replaces `run.verdict` with `_run_cio_step`'s fresh verdict
and persists it (`:7112`) WITHOUT re-stamping — despite computing `ctx.next_convene_delta`
itself (`:7037-7039`) and using `_reference_close(profile)` for banking (`:7129`). The
next convene's `_room_delta_context` reads exactly these fields (`:5787-5793`) → the delta
line silently degrades to absence on the run after a retry, and the verdict card loses the
stamped fields the outage verdict carried. Silent data regression on the verdict path —
Tier A. Real, verified line by line.

### MAJOR-2 (foreign #2 — REAL). A soft-deleted journal entry is resurrected by the retry's append fallback

`update_by_reference`'s docstring promises "a user who deleted their Room's journal entry
gets no entry resurrected by a later CIO retry" (`journal_store.py:339-341`) and returns
`None` for soft-deleted rows. Its only caller treats `None` as "missing" and appends a
fresh entry (`room_runner.py:7142-7148`), collapsing "never existed" (should not happen)
and "the user deleted it" (a real, reachable state) into one branch. User data-agency
defect, directly contradicting the primitive's own documented guarantee. Real, verified.

### MAJOR-3 (foreign #3 — REAL). Mobile never parses `cio_retry_available` / `cio_retried` from GET payloads — the retry offer dies on the reconnect path

`RoomRunSnapshot.fromJson` (`mobile/lib/models/room.dart:195-221`) omits both keys (and
`refunded`), and `_recoverViaPolling`'s final `copyWith` (`room_providers.dart:625-633`)
sets no cio flags — so after a dropped-socket recovery (the 90 s polling path) an eligible
run renders `done` with `cioRetryAvailable == false` and the button never appears. The
backend computes the flags on GET and list (`api/room.py:431,537`) — a delivered surface
with no consumer. The architect disclosed "RoomRunSnapshot not extended" as out of the
brief's scope, but the polling-recovery path is IN the live-session scope and loses the
offer exactly where outages cluster (flaky networks), and the 4 h eligibility window
implies come-back-later is an intended flow. MAJOR — the feature's core promise ("offer
the option to the customer") is undeliverable except to a user watching live when the
`done` event arrives.

### MINOR-1 (foreign #4 — real, downgraded to MINOR). No `live` guard on the retry

`retry_cio_step` computes `live = gateway.has_real_provider()` at retry time
(`room_runner.py:7043-7044`); a False there routes `_run_cio_step` through the scripted
`_assemble_verdict` branch (`:4784-4785`), persisting/banking/journaling a canned APPROVE
as the CIO's real verdict. Reachable only if the provider registration is removed and the
process restarted inside the 4 h window — on Alpha the vLLM provider is registered, and in
that misconfigured state fresh rooms would run scripted too, so this is the app's
sanctioned mock mode rather than a CR237-specific hole. Still, the honest shape is a
refusal ("the CIO is unavailable — try later"), since the retry exists precisely because a
non-live answer was not acceptable the first time. MINOR.

### OUT-OF-SCOPE (foreign #5 — real but pre-existing/acknowledged, not caused by this lane)

The `_sweep_stuck_runs` retry-exhausted and `_respawn_run_from_row` abandoned refund paths
never set `refund_recorded`, and `run_was_refunded`'s `status == "failed"` short-circuit
(`room_runner.py:772-773`) reports True even when that refund threw. Documented in the
predicate's own docstring as deliberately-unchanged CR039 shape; masked from users by the
short-circuit. Recorded for the architect to mint a DEF if it wants the ground-truth flag
uniform.
