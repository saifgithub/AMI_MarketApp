# DEF053 — audit lane (architect)

**Item:** DEF053 — Fundamentals Analyst prompt overclaimed full financial
statements, forward guidance, EV/EBITDA/P-S/FCF-yield multiples, peer comparison,
and capital allocation history, while `sector_pe` (`room_runner.py:241`, before this
fix) was always `rng.uniform(15, 25)` regardless of `use_real_market_data`. Split out
of CR033 (docs-only, AT:R57) into its own Defect at Saiful's request. Register:
[`docs/defect/def_list.md`](../../../docs/defect/def_list.md) DEF053. Full spec:
[`DEF053_fundamentals_analyst_oversold_scope.md`](../../../docs/defect/DEF053_fundamentals_analyst_oversold_scope/DEF053_fundamentals_analyst_oversold_scope.md).

**depends-on:** none.

**Head SHA:** `49e60dd`

## What was done

Checked Alpha Vantage's `OVERVIEW`/`EARNINGS` endpoints live against a real API key
(confirmed real response shapes, not assumed from docs) — then found a cheaper,
key-free source: yfinance's own `Ticker().info` dict (already the fetch path
`fetch_live_fundamentals()` uses) already carries, verified live against
AAPL/MSFT/NVDA/GME before writing any code:

- `priceToSalesTrailing12Months` → real P/S
- `enterpriseToEbitda` → real EV/EBITDA
- `pegRatio` → real PEG
- `freeCashflow` + `marketCap` → real FCF yield, computed as
  `freeCashflow / marketCap × 100` (verified this handles GME's negative FCF
  correctly — a real negative yield, not hidden or crashed on)
- `dividendYield` → real dividend yield (`None` for non-payers, e.g. GME)
- `sector` / `industry` → real classification
- `targetMeanPrice` + `recommendationKey` → real analyst consensus, explicitly
  labeled "Street view — NOT company guidance" everywhere it's rendered

Wired into `fetch_live_fundamentals()` (`fundamentals.py`) — reaches every user via
`use_real_market_data` alone, no `ALPHA_VANTAGE_API_KEY` dependency — and surfaced in
both `build_live_data_block()` (1-on-1) and four new `room_prompts.py` helper
functions (`_valuation_line`, `_sector_line`, `_capital_allocation_line`,
`_analyst_line`), each independently present/absent based on what yfinance actually
returned for the ticker.

`sector_pe` removed entirely — from the synthetic profile construction
(`room_runner.py`), from `_format_profile()`'s P/E line, and from the Fundamentals
Analyst's scripted-fallback template (which referenced `{sector_pe}` directly) —
rather than left as a parallel fake number alongside the new real fields.

**Bonus, near-zero cost:** `EarningsInfo.eps_estimate` (already fetched by CR023's
earnings overlay, never surfaced) now flows into the profile as
`next_earnings_eps_estimate` — a genuine forward consensus EPS tied to the real
upcoming earnings date.

`content/agents/fundamentals_analyst.md` rewritten to claim exactly this real scope,
with an explicit "financial statements not available" / "buybacks and M&A history not
available" disclaimer for what's still genuinely absent.

## Why this is safe / minimal

- **No new external dependency**: everything shipped via yfinance, already a
  dependency, already the fetch path in use. Zero new API keys, zero new network
  surface.
- **Additive-only wiring**: every new field is `if value is not None: out[...] = ...`
  — missing data for a ticker (e.g. GME has no dividend, no analyst rating) omits the
  field rather than fabricating or crashing. Tested explicitly (GME-shaped fixture:
  negative FCF, `dividendYield=None`, `recommendationKey="none"`).
- **`"none"` string is not a rating**: `recommendationKey` can literally be the string
  `"none"` for uncovered tickers — explicitly filtered out (`if rating and rating !=
  "none"`), tested, so a ticker with no analyst coverage doesn't render "None" as if
  it were a real consensus.
- **`sector_pe` removal has zero blast radius**: grepped for every reference before
  removing (4 total: the synthetic construction, the format-profile line, the
  scripted-fallback template, one doc comment) — no test asserted the old value.

## Addendum (pre-audit-verdict, folded into round 1)

Before seeing the auditor's verdict, proactively hardened `_num()` (`fundamentals.py`)
with an explicit `math.isfinite()` check — applying DEF052's F1 lesson (round 2,
`762455b`) to this sibling module rather than waiting to get bounced for the same
class of bug. Turned out the auditor's own COMPLETE verdict independently found and
flagged the identical gap as two non-blocking OUT-OF-SCOPE observations: #1 a NaN
value rendering as the literal string `"nan"` in the new DEF053 fields, and #2 a
**pre-existing** crash risk (predating this Defect) in `rev_growth`/`profit_margin`/
`net_cash`'s `round()` calls, which lack `ndigits` — `round(nan)` raises, same class
as F1. The single `_num()` fix closes both, since every numeric field (old and new)
routes through it.
