## The MAJOR — both class guards are vocabulary-narrow, not defect-narrow

**DEF245's guard, `test_no_agent_prompt_models_a_downside_with_a_literal_percentage`,
requires one of `downside|drawdown|loss|fall|drop` near a percentage.**
Its own docstring already documents one prior narrowing (MUT-4: word order),
and I found the vocabulary itself is just as narrow. None of these match
the regex:

```python
"if X happens, we're looking at a -25% correction"     # MISS
"if X happens, expect a -25% decline"                  # MISS
"if X happens, expect a -25% retracement"               # MISS
"if X happens, expect a -25% pullback / slump / plunge" # MISS (all three)
"if X happens, price could see a -25% haircut"          # MISS
"if X happens, we're looking at -25%, and that is more
 likely than consensus thinks"                          # MISS
```

The last one is the original DEF245 defect text with the word "downside"
removed from its label — the actual bear_researcher.md bullet was
`"Quantify downside: \"if X happens, we're looking at -25%...\""`, and the
guard only catches it because "downside" happens to sit in the label
before the colon, on the same line. Strip that one word and the identical
defect, in the identical worked-example shape, ships silently in any of
the 12 prompt files.

**DEF244's guard, `test_no_researcher_is_asked_for_a_position_size`,
requires one of `suggest|propose|recommend|output specific` alongside
`siz`.** Same shape of gap:

```python
"- Quantify your ideal position size given conviction."   # not flagged
"- State the position size you would take."               # not flagged
"- Give a specific sizing figure based on conviction."     # not flagged
"- End with a sizing conclusion."                          # not flagged
```

All four contain "siz" and no owner, and would reintroduce exactly the
defect this guard exists to prevent — the researcher independently
concluding a position size — without tripping it.

**Why this crosses to MAJOR rather than a residual-miss note.** Both
docstrings state a general claim: "The class, not the instance," and "if
either researcher regrows the demand, this is red." That's a stronger
promise than the round-6/round-7 "designed miss, disclosed and accepted"
pattern elsewhere in this programme — these two guards are explicitly
pitched as the thing that stops the *next* agent-file edit from
reintroducing either defect, on *any* of the 12 files, and a plain
synonym swap defeats both. Given the round's own MUT-4 already found and
partially fixed the identical failure mode (word order) in the same
regex, the vocabulary gap is the same class of miss recurring one level
over, not a new kind of risk.

**Not prescribing the exact word lists** — that's a losing game with
natural language regardless of how long the list gets — but two shapes
seem worth considering: (1) narrow the guard's *positive* claim to match
what it actually checks ("no `downside/drawdown/loss/fall/drop` word
sits within N chars of a literal %", stated as exactly that, not as "the
class"), so nobody downstream over-trusts its coverage; or (2) widen
significantly and accept the list will never be complete, documenting
that explicitly the way DEF231-233's `clear`-verb work eventually did
after several rounds of exactly this same escalation.
