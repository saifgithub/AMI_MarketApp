## Root cause

`watchlistNotifierProvider` (`mobile/lib/state/watchlist_providers.dart`) never fetched on creation.
Unlike `simNotifierProvider` — which bootstraps via `Future.microtask(n.refresh)` at provider
creation (`sim_providers.dart:139`) — the watchlist only ever loaded on a manual pull-to-refresh or
after an add/remove. So a cold app launch showed the empty state even when the user had saved
tickers.

## What changed / why

| Piece | Change |
|---|---|
| mobile | `mobile/lib/state/watchlist_providers.dart` — the provider now does `Future.microtask(n.refresh)` on creation, mirroring `simNotifierProvider`'s existing bootstrap pattern exactly. Doc comment updated ("Loads once on provider creation…"). |
