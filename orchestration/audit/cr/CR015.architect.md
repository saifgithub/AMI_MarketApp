## Deferred (disclosed)

1. **C1 — glass sheets.** Applying `GlassPanel` to the 3 bottom sheets means changing the modal
   geometry (`backgroundColor: transparent` + wrap + rounding), which interacts with keyboard
   `viewInsets` / `isScrollControlled` / flush-vs-floating — device-visual and regression-sensitive,
   not safely verifiable in a blind build. Deferred to a follow-up with device testing. (D-062 pins
   dark-only, so `GlassPanel`'s existing dark `AmiColors.glass` fill is already correct; the "light-aware
   fill" note is moot until v1.1 light theme.)
2. **Bulk SnackBar routing.** The remaining ~20 SnackBar sites — `sign_in_screen` (10) + `merge_sheet`
   (2) are **auth error-path** toasts in a sensitive flow; `settings`/`journal` are lower-risk. Routed
   the high-visibility feedback toasts now; the auth/merge sweep + the rest land in a focused follow-up
   with device testing. `trade_ticket_sheet` intentionally kept its bespoke success SnackBar (it pops
   the sheet *then* toasts — an overlay on the popping context is fragile).
