## What and why

Saiful, 2026-09-25: *"We have been mixing the term PM and CIO in the app, and in the
lesson. This is because we had renamed the PM to CIO but not all were updated."*

CR160 (2026-08-20) renamed the agents: Portfolio Manager → Chief Investment Officer,
Trader → Execution Desk, Market Analyst → Technical Strategist, Social Media Analyst →
Flow & Positioning, News Analyst → Macro & Events, Aggressive/Conservative/Neutral
debaters → Risk Officers (Neutral → Balanced). Its guard (`test_cr160_agent_rename.py`)
only scanned `content/`, so the app strings, one prompt block, the website chatbot and
the bare abbreviation "PM" were never covered.

- `agent_id`s, file names, code identifiers, log keys (CLAUDE.md naming rule).
- "(PM)" as the Philip Morris ticker; "Trader A/B/C" as example characters in lessons;
  "PM" as a time of day.
- AR/MS translations: every changed EN id carries `retranslate:[ar,ms]` (the i18n lane
  translates; nothing hand-copied, DEF295 gate green).
- `website/terms/index.html` (live Terms v4.0): Saiful ruled "Publish v4.1, label-only";
  that is a separate worker, deployed after Architect review.
