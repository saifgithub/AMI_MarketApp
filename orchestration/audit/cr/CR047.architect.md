## What was done

Funnel gate for exhausted Floor-Pass Room convenes, Floor-Pass-only, armed by
`GTM_FUNNEL` (`none|winzip`).

Backend:
- `config.py`: `gtm_funnel: Literal["none","winzip"] = "none"` (Literal =
  boot-fails loudly on typo, CR040) + `winzip_cooldown_minutes: int = 5`.
  Forwarded in `docker-compose.yml` api-alpha env → config-compose parity holds.
- `models.py`: `users.room_cooldown_until` (nullable timestamptz) + migration
  `c5d6e7f80019` (down_revision `b4c5d6e70018`, current head).
- `credit_service.py`: `InsufficientCredits` gains `funnel` + `cooldown_until`.
  `spend()` winzip branch, ORDER IS LOAD-BEARING — cooldown checked BEFORE the
  balance test: (1) cooldown active → raise winzip 402, no grant, no spend,
  regardless of balance; (2) balance ≥ cost → normal spend; (3) exhaustion →
  set `credit_balance = cost`, `room_cooldown_until = now + cooldown`, log
  `credits_added/winzip_reset`, raise winzip 402. Reset tops up to exactly one
  Room, so if cooldown were checked after balance the just-granted credit would
  let the next convene straight through and the wait would never bite.
- `room.py`: 402 `detail` gains `funnel`, `cooldown_until` (ISO),
  `retry_after_seconds`.
- `mandate.py` + `schemas/mandate.py`: expose `room_cooldown_until`.

Mobile:
- `api_exceptions.dart` (new, first custom exception): `InsufficientCredits
  Exception` reading the nested `detail` body.
- `api_client.dart` `streamRoom`: on `statusCode == 402`, read the body →
  throw the typed exception (was a generic `Exception('HTTP 402…')`).
- `room_providers.dart`: `RoomState.paywall` + `copyWith/clearPaywall`;
  `start()` catches `InsufficientCreditsException` before the generic catch.
- `room_screen.dart`: `_PaywallCard` — amber `AccentCard`, live 1s countdown,
  `flutter_tts` speaks "Your Room is available now" at 0 (best-effort female en
  voice; swallows TTS failure), "review a Training session while you wait" CTA →
  `LessonsScreen`. Falls back to a plain "resets on <date>" card when funnel is
  null (hard wall).
- `mandate.dart`: `UserMandate` gains `roomCost/creditAllowance/creditsResetAt/
  roomCooldownUntil` + `roomCooldownActive`.
- `app_en.arb`: `roomWinzip*` + `roomPaywall*` keys; l10n regenerated.
- New dep `flutter_tts: ^4.2.0` (just_audio can't synthesize speech).

## Why this is safe / minimal

- **Default off.** `gtm_funnel` defaults `none` → legacy CR039 behaviour is
  byte-identical until `GTM_FUNNEL=winzip` is set in melehost `.env`. Promoting
  the code does not change Alpha behaviour on its own.
- **Floor-Pass + Room-only.** Winzip branch requires `amount is None` (Room, not
  1-on-1) AND `eff == FLOOR_PASS` AND `gtm_funnel == "winzip"`. Paid plans and
  1-on-1 spends fall to the unchanged legacy branch. Pinned by
  `test_winzip_does_not_touch_paid_plans`.
- **No double-grant.** The cooldown-active branch returns without re-granting;
  the reset happens once per window. Pinned by
  `test_winzip_cooldown_blocks_without_double_granting` (balance stays at cost,
  cooldown timestamp unchanged, exactly one `winzip_reset` event).
- **Deferred-raise contract preserved.** The winzip re-grant is committed inside
  the session before the raise, same pattern CR039 already relies on.
- **Mobile fail-open on TTS.** Voice is wrapped in try/catch; a device with no
  usable voice engine still shows the Convene button and countdown.
