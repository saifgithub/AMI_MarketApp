## Why this is safe / minimal

- **Purely additive to a pure library.** No existing `trading_math` function, signature, or return convention changed; `indicators/risk/sizing/trade/valuation/portfolio` untouched. No app service imports the new modules yet → zero live-path risk, zero behaviour change on Alpha.
- **Library contract held:** pure functions over primitives, no I/O/config/logging/pydantic, no imports from the rest of `app` (grep-proof above), copy-portable.
- **Degrade loudly (CR040):** every unusable input path returns None (caller omits the figure) rather than a defaulted/silently-wrong number — fractional bond periods, unattainable YTM prices, unknown option kinds, flat-series correlation/beta/Sharpe, asymmetric/non-PSD covariance matrices, non-positive CAGR/drawdown inputs.
- **Convention consistency:** presented figures round at the boundary (2 dp; YTM 3 dp for bps); composable dimensioned stats (`variance`/`covariance`/`portfolio_variance`) stay unrounded like M05's `drawdown_pct`. Sample (n−1) convention single-sourced (M12 reuses M11's `variance`).
- **AMI naming / user copy:** none — code + internal docs only.
