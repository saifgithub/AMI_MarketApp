## What shipped

- `backend/app/services/room_runner.py`
  - `_build_sim_holdings_block(user_id, ticker)` — the always-present holdings block.
    Reads `sim.list_trades(user_id, status="open")` (aggregated per name), cash via
    `ensure_portfolio().current_cash`, `sim.total_value()`, marks via
    `sim.current_marks()`. Renders per-name `SYM ×qty (weight% of portfolio,
    unrealised ±$)` AND — critically — a dedicated line stating the DISCUSSED ticker's
    weight explicitly, `0%` when not held. Empty portfolio → explicit "Open positions:
    none — you hold nothing yet. You hold 0% of `<TICKER>`. Any BUY here opens a NEW
    position." Wrapped in try/except that renders `Portfolio unavailable this run.` on
    ANY failure — never returns empty/None (degrade loudly, CR040).
  - `_compose_portfolio_block(sim_block, alpaca_snap)` — precedence made explicit: sim
    is the portfolio of record; a linked Alpaca account (rare) is appended as a
    clearly-labelled external overlay. Returns ONE block.
  - `run()` builds the block UNCONDITIONALLY (no `alpaca_access_token` gate) and stores
    it on `_RoomContext.portfolio_snapshot` (renamed from `alpaca_snapshot`), threaded
    to both `build_room_messages` call sites (`_speak_one_agent` + `_stream_pm_response`).
- `backend/app/services/agent_prompts.py` — `build_agent_prompt` gains a
  `portfolio_snapshot` slot (appended before the 1-on-1-only `alpaca_snapshot` slot).

     "NEW position".

     `room_runner.get_sim_engine` to raise → asserts `Portfolio unavailable this run.`
     renders and the block is non-empty. There is NO code path in
     `_build_sim_holdings_block` that returns "" or None — verify by reading it: every
     branch (user_id None / empty portfolio / held / except) returns a populated block.
   - `test_runner_injects_portfolio_snapshot_at_every_call_site` — source-level regex
     asserting BOTH `build_room_messages(...)` calls in `room_runner.py` pass
     `portfolio_snapshot=`, so the block cannot silently stop reaching an agent.

   the sim block unchanged when unlinked; when linked, the Alpaca text is a labelled
   *overlay* below the sim block (not a competing "YOUR PORTFOLIO"). The Room passes
   only `portfolio_snapshot` now (no separate `alpaca_snapshot` into
   `build_room_messages`), so there is exactly one portfolio block. Attack vector to
   check: confirm no residual `alpaca_snapshot=` reaches `build_room_messages`.

   function the Trader/PM ceiling and the safety floor read (CR046 M03). For risk_score=3
   the researchers now see `3.0%`. `test_researcher_prompts_carry_enforced_size_cap`
   (parametrized over Bull/Bear/Research-Manager) +
   `test_analyst_prompt_does_not_carry_researcher_cap_line` (targeted, not blanket).
4. **No DEF059-style silent path remains.** The bug was silence → confident fabrication.

   `test_long_only_clarification_absent_when_shorts_allowed`.
