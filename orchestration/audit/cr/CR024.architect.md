## Why this is safe / minimal

- **Real post text never touches the Room profile dict** — the one structure that
  also feeds the always-rendered scripted fallback. Only aggregate stats (buzz
  score, subreddit names, mention counts) reach that surface; verbatim Reddit
  content is confined to the LLM-only 1-on-1 context block with an explicit
  no-verbatim-quote instruction. This is the correct place to draw that line —
  aggregate stats are AMI's own derived signal, verbatim community text is not
  ours to redistribute.
- **Credential-materialization safeguard worked as intended**: an initially guessed
  Adanos domain+path was blocked before any live key left the Mac; the eventually
  used endpoint was confirmed from first-party (Adanos's own homepage), not a
  third-party guess.
- **No key set → behavior byte-identical to pre-CR024** (Stage 1's honesty-only
  wording, not a data claim) — `fetch_live_sentiment()` returns `None` immediately
  when `adanos_api_key` is unset.
- **Scripted-fallback fix was the actual highest-severity item found this session** —
  named real platforms in user-facing text with zero disclosure. Folding that into
  this CR rather than deferring it was the right call; a later-discovered severity
  escalation, not scope creep.
