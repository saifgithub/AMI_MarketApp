### The question

Saiful's complaint was that users see "PM" and "CIO", or "Trader" and "Execution Desk", used
for the same agent. So the lane has to meet two conditions:
1. No old label remains anywhere a user can read it. That includes AMI's own narration, because
   the model echoes whatever its prompt calls the agents.
2. A guard fails if an old label comes back. This is the second occurrence of the class, which
   is why it's registered as P37.

- **Over-correction (item 3):** none found. The safety-floor lessons
  (`*_ai_hallucinations_and_amis_safety_floor.en.mdx` and `274_…`) change only the label. All

### MAJOR-2 — the old labels are still in agent prompts and in one message users see

I scanned the string constants in `app/` with the AST and excluded docstrings. I validated the
scan on the known positive `room_prompts.py` at `9dca0d06^`, where it finds the two "Trader"
sites this lane fixed. Its hits at `f7eb4efa`:

- **`app/services/room_runner.py:631`, `PM_LLM_UNAVAILABLE_REASON`:** "AMI's analyst room lost
  its model connection before the **Portfolio Manager** could rule." This is the verdict
  `reason`, and `room_screen.dart:1318` renders it as `Text(verdict.reason)`. Users see it on
  every CIO outage. Careful: `is_llm_outage_verdict` (`:691`) compares it by exact equality
  against stored verdicts. Renaming the constant alone would stop old outage rows from being
  recognised, so the check has to accept both strings.
- **`app/agents/overlay_generator.py:789`:** the Execution Desk's own role block is headed
  `## Role guidance — Trader`. So that agent's LLM is told its name is "Trader".
- **`overlay_generator.py:927`:** the CIO's `INPUTS:` list reads "Trader's proposal".
- **`overlay_generator.py:912`:** a bare "PM" in the CIO block ("a risk_score=1 user's PM would
  reasonably PASS").

The lane fixed "the Trader" in `_PM_VERDICT_FORMAT` because the model "can echo it into
narration". That reasoning applies directly to the role header the Execution Desk reads about
itself. I did **not** measure how often narration on Alpha actually says "Trader". The
residue is in the prompt, and the echo is inferred.

`room_runner.py:632` and `overlay_generator.py` aren't in the "Deliberately left alone" list,
so this isn't a ruled exclusion.
