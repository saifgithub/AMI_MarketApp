### Item #1 — the waiver — **this is where the finding is**

Built a probe harness that loads the guard module and re-runs its own analysis with the waiver
set swapped, so every number below is measured, not read.

**Baseline:** 85 route handlers walked, 0 offenders. **Empty waiver:** 11 chains across exactly
the 9 handlers the Architect named — their claim reproduces exactly.

**The docstring's honesty claim —** *"removing a name here without fixing its call site should
turn this guard red again"* **— is measurably false for 7 of the 9 names:**

| dropped name | guard |
|---|---|
| `_marks_with_quotes` | RED (2 chains) |
| `preview` | RED (1 chain) |
| `current_marks` · `current_marks_with_source` · `current_price` · `submit` · `evaluate_outcomes` · `manual_close` · `_build_room_sector_context` | **STILL GREEN** |

Cause: the names **shadow each other**. `current_marks` is reached from `sim.py:126`, but its only
blocking path is `_marks_with_quotes`, still waived → pruned; `current_price` is reachable only
through `submit`/`evaluate_outcomes`/`manual_close`, all still waived → never entered. So the
waiver is not revocable-by-name; it is a blanket suppression that only *looks* like honest
bookkeeping.

**The consequence is worse than stale bookkeeping.** The prune is applied to the whole subtree, so
a **brand-new** blocking call added inside a waived function is invisible. Proved it: injected
`self.current_news("AAPL", 1)` as a fresh first statement of `SimEngine.submit` — reachable from
`POST /sim/trade` (`submit_trade`), the hottest write path in the app — and the guard stayed
**GREEN, 1 passed**. That is the Architect's own stated failure condition ("a guard that goes
green on a genuinely new regression is worse than no guard") and this project's DEF038/DEF063
lesson in a different costume. Reverted, tree clean.

**Name-collision sub-question:** only one waived name collides today —
`merge_service.py:110::preview`. Read it: DB-count only, no network leaf, so nothing unrelated is
masked *today*. The collision is latent, not live.

**Recommended fix (small).** Either scope the waiver to `(module, function)` and prune only the
edge rather than the subtree, or — cheaper and stronger — add a companion test that runs the same
walk with an **empty** waiver and asserts the offending-route set equals exactly the 9 known
DEF120 routes. Then DEF120 stays waived while a 10th route (i.e. a genuinely new regression, or a
DEF120 fix that missed a site) turns that test red.

### Item #2b — the `to_thread` exemption is **inverted**

`_to_thread_wrapped_call_ids` exempts any `ast.Call` sitting as `asyncio.to_thread`'s first
positional argument. Probe P-E: `q = await asyncio.to_thread(sim.current_quote(ticker))` → guard
**GREEN**. That line genuinely blocks the event loop (the leaf is called inline) *and* then raises
`TypeError` in the worker because a `Quote` isn't callable. The shape it exempts is **never
correct** — passing a *called* leaf to `to_thread` is always a bug. It should be flagged, not
waived. MINOR only because the laundered code is loudly broken at runtime, so it cannot ship
silently.

### Findings

1. **MAJOR** — the waiver prunes the whole subtree by bare function name, so any blocking call
   added inside a waived function is undetectable. Mutation-proved: a fresh `self.current_news(…)`
   in `SimEngine.submit`, reachable from `POST /sim/trade`, leaves the guard green. Separately, the
   docstring's stated integrity property is false for **7 of 9** waived names (measured, name
   shadowing). Fix: scope the waiver to `(module, function)` + prune the edge only, or add an
   empty-waiver companion test pinning the offender-route set to exactly the 9 known DEF120 routes.
2. **MINOR** — `_to_thread_wrapped_call_ids` is inverted: `asyncio.to_thread(leaf(x))` both blocks
   the loop and `TypeError`s at runtime, yet is exempted (probe P-E → green). Flag it instead.
3. **MINOR** — the live Alpaca `httpx` pair is held by a comment. The stated reason for excluding
   httpx from the call-graph walk is independently confirmed true (85 bogus chains measured), but
   a non-graph inventory pin of `httpx.<verb>(` sites under `backend/app` would cost ~10 lines.
