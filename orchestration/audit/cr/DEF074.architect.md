# DEF074 — audit lane (architect)

**Item:** DEF074 — the Room fact-sheet dropped the computed 50-day technical support and rendered
the 52-week low as the "recent range" floor, diverging from the 1-on-1 surface. Found verifying
CR046 M01 was sent correctly to the live Alpha agents. Register:
[`docs/defect/def_list.md`](../../../docs/defect/def_list.md) DEF074. Full spec:
[`DEF074_room_drops_technical_support.md`](../../../docs/defect/DEF074_room_drops_technical_support/DEF074_room_drops_technical_support.md).

**depends-on:** none. (Related: CR046 M01 — this is a routing bug on the same technicals the M01
migration produces; M01's ledger changelog links it.)

**Head SHA:** `d014c95`.

## What was done

`backend/app/services/room_prompts.py::_format_profile` — one line. The range line rendered
`profile['low']`/`profile['high']` (52-week, from the fundamentals overlay) as the range while
`profile['support']` (the real 50-day technical support that `room_runner.py:341` sets from
`technicals.support`) was never rendered — computed and silently dropped. Now renders:

```
Recent range: $<support>–$<breakout> (52-week: $<low>–$<high>)
```

The coherent 50-day technical pair (support–breakout) is the floor/ceiling; the 52-week range stays
as explicit parenthesised context. This surfaces the computed support and makes the Room agree with
the 1-on-1 path (`build_technicals_context_block`, which already renders `technicals.support`).

## Why this is safe / minimal

- **One line, display-only.** No change to any computed value, to `_profile_for_ticker`, to the
  overlay cascade, or to the fallback (synthetic support when technicals is None is unchanged — the
  disclosure header still flags live-vs-synthetic globally). Only *which already-computed field* the
  Room renders changed.
- **No number is invented.** `support`/`breakout`/`low`/`high` all already exist in the profile;
  the fix reads `support` instead of `low` for the floor and keeps `low`/`high` as labelled context.
- **Direction chosen** = surface the technical support (the option Saiful acknowledged), because
  `compute_technicals` computes it specifically to give agents a real support and the sibling
  `breakout` was already being shown — restoring the matched pair. The 52-week low is not lost.
