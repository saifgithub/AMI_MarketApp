You returned DEF247 COMPLETE and I shipped it. Then I ran the post-promotion


`_STANCE_LINE_RE` accepted an optional `[`, never a `**`. So the line was neither
stripped nor read: raw machine syntax on the user's screen **and** a null stance
in the comb — the exact pair DEF147 split these jobs to prevent, and the pair

DEF247 widened **position**. I never asked about **decoration**. Same P16 shape

Every debator turn ever stored, by era:

|---|---|---|
| before 2026-08-10 | 2,974 | **0** |
| since | ~700 | **5** |

Two shapes, both real: `**STANCE: …**` and `**[STANCE: …]**`. All five are frozen

`test_the_fixture_holds_every_emphasised_turn_the_corpus_has` asserts both shapes

Nothing in the prompt invites emphasis — `_STANCE_FORMAT` shows the envelope bare
and says nothing about formatting. This is drift in the model's markdown habits,
which is the standing argument for the DEF147 split: **the set of shapes a model
emits is not knowable in advance, so the strip must be generous and only the read
may be fussy.**

## The fix

```python
_EMPHASIS = r"[*_]{0,2}\s*"
_STANCE_LINE_RE = re.compile(rf"^\s*{_EMPHASIS}\[?\s*{_EMPHASIS}STANCE\s*:", re.I)
_ENVELOPE_TRIM_RE = re.compile(r"^[\s*_]+|[\s*_]+$")
```

The trim is not cosmetic: without it the last field swallows the closing `**` and
the comb renders `$1231.94 entry**`. Leading/trailing runs only — an inner `_`
belongs to whatever the agent was naming (`free_cash_flow inflect`).
