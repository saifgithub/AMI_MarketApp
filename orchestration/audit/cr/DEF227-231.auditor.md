## Attack #1 — DEF229(a)'s unwrapping: broke it, found a real (non-live) structural fragility

Read `history_with_source` and the two `history_with_source` overrides on
`CachingProvider`/`FallbackProvider`. `FallbackProvider.history_with_source`
recurses correctly (`history_with_source(self._primary, ...)` then falls
through to `self._secondary`). `CachingProvider.history_with_source` does
**not** recurse — it returns `self.history(ticker, period), getattr(self._inner,
"name", "unknown")`, on the stated assumption *"the cache wraps exactly one
leaf, so a cache hit is attributable to that same leaf."*

**That assumption is true today and enforced nowhere.** Confirmed the real
stack (`get_market_data_provider`): `FallbackProvider(primary=CachingProvider(yfinance_leaf),
secondary=MockWalkProvider())` — `CachingProvider._inner` is always a bare
leaf, never a `FallbackProvider`, so the shortcut is correct for the only
composition that exists. But if a future stack ever wrapped
`CachingProvider` around a `FallbackProvider` instead (composing them the
other way), a cache hit for bars that were actually served by the
*secondary* leg during a prior outage would report `self._inner`'s own
static `.name` (the fallback stack's name, e.g.
`"fallback(yfinance->mock_walk)"`) — which is neither the true serving leaf
nor an exact match in `SYNTHETIC_HISTORY_SOURCES`, so a synthetic series
could silently pass the refusal check under that reordering. **Not live**
— reproduced the two tests that exercise the actual production topology
(`test_history_with_source_reports_the_leaf_that_served_the_bars`,
`test_history_with_source_reports_the_real_leaf_not_the_cache_wrapper`) and
confirmed both correctly cover today's only real composition. Flagging as
MINOR: the invariant is documented in the method's own comment but not
structurally enforced (e.g. `CachingProvider.__init__` could assert
`not hasattr(inner, "history_with_source")` or `CachingProvider` could
recurse via the module-level `history_with_source(self._inner, ...)`
instead of the `getattr` shortcut, which would cost nothing today and
remove the fragility). Not gating — no path to it in the current singleton
factory, which constructs the stack in exactly one place.

**Mutation-proof, reproduced myself:** made `CachingProvider.history_with_source`
report its own name (`self.name`) instead of the inner leaf's —

```text
FAILED test_history_with_source_reports_the_real_leaf_not_the_cache_wrapper
+ cache(yfinance)
```

Exactly the named test, matching the submission's M5 exactly. Reverted.
