## 4. Attacked the guard's own coverage — this is the risky dimension

`_relative_source_path_literals` only matches an `ast.Call` node named `Path`
with a single `ast.Constant` string first argument. Probed the bypass surface
directly against the function:

```
baseline      Path("app/services/health_gate.py")                  -> caught
Path(var)     p = "app/services/health_gate.py"; Path(p)           -> MISSED
Path()/join   Path("app") / "services" / "health_gate.py"          -> MISSED
open(), no Path  open("app/services/health_gate.py")               -> MISSED
f-string      Path(f"app/services/{name}.py")                      -> MISSED
os.path.join  os.path.join("app","services","health_gate.py")      -> MISSED
string concat Path("app/" + "services/health_gate.py")             -> MISSED
pathlib.Path(...) attribute form                                   -> caught
```

**MINOR** — real, substantial residue: every non-literal or non-`Path(...)`
construction of the same cwd-relative read escapes undetected. Judged MINOR
not MAJOR because (a) the guard's own docstring says plainly "Only `Path(...)`
calls are inspected" — it does not overclaim general coverage; (b) all 3 real
occurrences this session (2 in `test_cr136_health_gate.py`, 1 latent in
`test_cr124_compose_hardening.py`) are exactly the shape it does catch — this
is the actual failure mode observed in this codebase, not a hypothetical one;
(c) widening to catch `open()`/`os.path.join`/f-strings needs real dataflow
analysis or risks flagging legitimate tmp-file/log-key/config strings, the
exact noise-to-disable tradeoff the docstring already reasons about and
declines. Accepted, not gating.
