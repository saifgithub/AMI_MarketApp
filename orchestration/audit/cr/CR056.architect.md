# CR056 — audit lane (architect)

**Item:** CR056 — one universal grounding directive prepended to every LLM call: use only
explicitly-provided facts; never assume/infer/invent/recall absent data. Defence-in-depth for the SCHD
phantom-holdings class (behavioural counterpart to CR055's structural data-supply fix).

**Gate:** independent. The directive touches the single chokepoint every model call routes through, so a
mistake is system-wide. Two site-specific caveats make it break-prone: (1) the MockProvider routes on
agent-id substrings in the lowercased system prompt — a stray token mis-routes it; (2) the PM safety
floor must stay last.
