# Question: I'm not receiving notifications

**Keywords:** notifications, push, not receiving, no alerts, reminders not working, muted notifications
**Category:** technical
**Source:** support_faq.txt + troubleshooting.txt (melehost), merged 2026-07-24.

**Answer:** Check both the OS and in-app settings:
1. iPhone: Settings → Notifications → AMI Trade → Allow Notifications.
2. Android: Settings → Apps → AMI Trade → Notifications → enable.
3. In the app: Settings → Notifications → make sure the relevant category isn't muted.
4. Restart the app after changing any notification setting.

If notifications still don't arrive after all of the above, escalate — ask for device model and
OS version.
