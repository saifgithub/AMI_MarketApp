# Question: The app is slow / laggy / unresponsive

**Keywords:** slow, laggy, lag, unresponsive, freezing, stutter, performance, loading forever
**Category:** technical
**Source:** support_faq.txt + troubleshooting.txt (melehost), merged 2026-07-24.

**Answer:** Common causes: older devices (under 3GB RAM), low storage (keep at least 2GB free),
or a weak network connection. Try:
1. Close other apps running in the background.
2. Free up storage space.
3. Use Wi-Fi instead of mobile data if possible.
4. Clear the app cache and update to the latest version.
5. Restart the device.

This is more noticeable on older/budget devices — that's expected, not a bug, unless it's a
sudden regression on a device that used to run fine (worth escalating if so).
