# Payoff diagrams — intrinsic & time value

An option's premium is really two numbers stacked together: intrinsic value (what it would be worth if you exercised it right this second) and time value (everything extra you paid, betting the intrinsic value grows before expiry). At expiry, time value is gone entirely — only intrinsic value survives, and the option's payoff is that intrinsic value minus what you originally paid. After this lesson you'll be able to read a payoff diagram and separate "this is worth something" from "this made money."

## Example

Take a hypothetical AAPL $200-strike call, bought for a $6.50 premium (illustrative — not a live quote). At any point before expiry, that $6.50 splits into intrinsic value and time value. At expiry, only intrinsic value survives — which is exactly why the Greeks lesson that follows treats time value as something that decays away.

Run the numbers. If AAPL finishes at $180, $190, $195, or even exactly $200 at expiry, the call is out of the money — the right to buy at $200 is worth nothing when AAPL is at or below $200, so intrinsic value is $0 and the payoff is -$6.50: a full loss of the premium, no matter which of those four levels AAPL actually landed on. The break-even for this call is $206.50 (strike plus premium) — at that exact price, intrinsic value equals $6.50, which exactly offsets what you paid, so payoff is $0.00. You don't clear a profit until AAPL trades above $206.50. At $210, intrinsic value is $10.00 and payoff is $3.50. At $220, intrinsic value is $20.00 and payoff is $13.50. Below the strike, payoff sits flat at -$6.50 no matter how far below; above break-even, payoff rises dollar-for-dollar with the stock.

The same $200 strike and $6.50 premium as a put runs in the opposite direction: break-even is $193.50 (strike minus premium). At $180, intrinsic value is $20 and payoff is $13.50; at $190, intrinsic value is $10 and payoff is $3.50; at $193.50 (break-even), intrinsic value is $6.50 and payoff is $0.00; at $200 or $210, the put is worthless — intrinsic value $0, payoff -$6.50.

## The trap

Beginners treat "in the money" as a synonym for "profitable." It isn't. An option can be in the money — worth something if exercised — and still be a losing trade if it hasn't cleared the break-even yet. The correct mental model: payoff isn't measured against the strike, it's measured against strike plus premium (for a call) or strike minus premium (for a put). Between the strike and the break-even, you're recovering losses, not booking gains — and most beginners stop tracking the position the moment it flips "in the money," exactly the range where it's still underwater.

## The steelman

A skeptic might argue payoff-at-expiry diagrams overstate the risk, since almost nobody actually holds an option all the way to expiry — most retail traders close positions early, so the flat -$6.50 floor rarely matters in practice. The falsifier: closing early changes *when* you realize the loss, not the direction time value is working. Theta (time decay, covered next lesson) erodes an unprofitable long option every single day it's held, whether closed early or not — the payoff diagram describes the destination the position is drifting toward the whole time, not just a rule that only bites at the final bell.

## Takeaway

An option's payoff at expiry isn't the stock's move — it's the stock's move minus the premium you paid, and until you clear the break-even, being right about direction still loses money.

*Where this comes from: the standard option payoff decomposition — intrinsic value plus time value — used across every exchange-listed option pricing model.*
