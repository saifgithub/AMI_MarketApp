# Data-mining & survivorship bias

Survivorship bias creeps in when a backtest's universe of stocks, funds, or indices quietly excludes the ones that failed and were delisted, liquidated, or dropped along the way — leaving only the survivors in the sample. Because failure is exactly what a real investor risked encountering, testing only on survivors systematically overstates how well a strategy actually performed on the choices that were genuinely available at the time. Related but distinct: data-mining bias is testing so many strategy variations against the same data that some will look good purely by chance, the multi-strategy cousin of the single-strategy overfitting problem from two lessons ago.

## Example

Say a backtest is built on a universe of 100 funds that existed in 2005. By 2025, **30 of them shut down** — liquidated, merged away, or delisted — leaving **70 survivors** with an average return of **+8% per year**. A backtest that only includes today's fund list (the 70 survivors) reports that 8% figure as "the historical performance of this universe." But an investor in 2005 couldn't have known in advance which 30 would fail — the true historical universe included all 100. Assume the 30 that shut down averaged -5% per year before closing (a reasonable stand-in for "failing badly enough to be shut down"). The true, survivorship-corrected blended return = (70 × 8% + 30 × -5%) ÷ 100 = (560 - 150) ÷ 100 = 410 ÷ 100 = **4.1% per year** — barely half the 8% the survivors-only backtest reported.

That 8%-versus-4.1% gap is pure survivorship bias, with no strategy skill involved on either side — it's entirely a function of which funds were included in the tested universe. Any backtest run only on today's list of "still-existing" companies, funds, or indices carries this same silent inflation, whether or not anyone building it intended it.

## The trap

The trap is building a backtest from a current list of tickers, funds, or index members — because that's the easy, available data — without asking whether that list quietly excludes everything that failed along the way. It feels like a reasonable shortcut because "today's list" is the obvious dataset to reach for. The correct habit: before trusting a historical performance figure, ask whether the tested universe includes delisted, liquidated, or merged-away names from the period — and if it doesn't, treat the reported return as inflated versus the true historical experience, roughly in proportion to how much of the original universe failed.

## Takeaway

A historical return built only from today's survivors is not the true historical return of that universe — always weight in what failed before trusting the number.
