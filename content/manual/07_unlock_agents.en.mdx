# Unlock more analysts

You earn agents by passing lessons.

1. Open the **FLOOR** tab and tap **YOUR FIRM**. Dimmed hexes are locked.
2. Tap a locked agent. The sheet headed **HOW TO UNLOCK** lists that agent's gateway lessons, with a tick beside each one you have passed. Tap a lesson to start it.
3. Open each lesson and pass its quiz (see the lessons entry). Tap **GO TO LESSONS** to browse the full catalogue instead.

Each agent has its own list, so check the sheet for the agent you want. When the last lesson is passed you see **AGENT UNLOCKED**, and the agent appears lit in **YOUR FIRM**.
