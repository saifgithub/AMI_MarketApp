## yfinance availability (pyproject.toml:32)

yfinance >= 0.2.50 is already installed in the backend. The `Ticker(ticker).news` endpoint is part of the standard library — no new dependency.

## Graceful fallback requirement

News Analyst code must never break when:
- yfinance returns `None` (ticker not found)
- yfinance returns empty list (no news available)
- yfinance network timeout (rate limit, internet down)
- `USE_REAL_MARKET_DATA=false` in dev mode

The fallback is to render `recent_news=[]` and let the frontend display "No recent news available" gracefully.
