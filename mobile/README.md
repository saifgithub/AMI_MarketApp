# AMI Trade — Flutter app

Mobile-first client. iOS at alpha; Android-GMS + Android-HMS at v1.0/v1.1.

## First-run

The `ios/` and `android/` platform-specific folders are generated by `flutter create`. They're not in git yet — Saiful runs this once on his Mac:

```bash
cd "/Volumes/Extreme Pro/AMI_MarketApp/mobile"

# Generate iOS + Android scaffolding without overwriting our lib/ or pubspec.yaml
flutter create \
  --project-name=ami_trade \
  --org=ai.agenticmarketintel \
  --platforms=ios,android \
  --no-overwrite \
  .

flutter pub get
```

Then download fonts:

```bash
# Inter — https://fonts.google.com/specimen/Inter (download "Inter" zip)
# JetBrains Mono — https://fonts.google.com/specimen/JetBrains+Mono
# IBM Plex Sans Arabic — Phase v1.0 only

# Put into:
mkdir -p assets/fonts/Inter assets/fonts/JetBrainsMono
# (then unzip the .ttf files into those folders matching pubspec.yaml)
```

And copy assets from the AMI design system:

```bash
cp "/Volumes/Extreme Pro/AMI AI Design System/assets/hex_mesh.svg" assets/
cp "/Volumes/Extreme Pro/AMI AI Design System/assets/logo_hex.svg" assets/
mkdir -p assets/icons
```

## Run

```bash
flutter run -d ios            # iOS simulator
# or
flutter run                   # device picker
```

You'll see the **Design System Preview** screen with:
- Tier badges (Floor Pass / Trader / Floor Manager)
- The 12 agents arranged by family with different status states
- Hex buttons
- Glass panels with role-accent top borders

This screen is the temporary launch target while we wire up the real router in W2.
