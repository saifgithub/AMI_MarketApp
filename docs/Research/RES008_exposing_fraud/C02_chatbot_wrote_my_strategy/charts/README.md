  "Rules (plain English)" column per strategy, not a parseable family/classification

## Notes on specific figures

- **02a / 02b**: `p10_haiku` (Prompt 10 · Haiku) never trades, so its as-shown
  gross return is exactly 0.0 and it is excluded from "looks profitable" (28 of 29).
  It is shown as a dim zero-height bar labelled "never trades" rather than dropped,
  so the row count still reads 29.
- **03**: two tickers (`ETH-USD`, `BTC-USD`) only appear in the three Bitcoin-prompt
  strategies (`p09_*`); every other strategy was evaluated on 22 equities. Cells for
  a ticker a strategy was never run on are grey ("not evaluated"), not dark ("did not
  beat"). Total cells = 578, lit cells = 38 (BA 15, DIS 12, PFE 10, ETH-USD 1),
  matching `RESULTS.md` §2.
- **01**: sorted from worst to best mean placebo percentile (holdout). `p10_haiku`
  has no `s2_mean_placebo_percentile` (it never trades, so there are no entries to
  score against placebos) and is drawn as a zero-length bar with a text note rather
  than silently dropped.
- Plain-word prompt labels (e.g. "Prompt 8 · Opus") map prompt number → the model
  name from `gate_results.json`; the one-line prompt text itself is summarised in
  `make_charts.py`'s `_PLAIN_PROMPT` dict for the record but not shown on screen.
