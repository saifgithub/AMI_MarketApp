## Skipped / not sourceable from `out/`

Nothing was skipped. All five chart-pack rows in `VIDEO_BRIEF.md` (three
restyles + two "to draw") are covered by the first six PNGs above; `06` was added in review because the script's beat 7 shows the 5× path; no `.npz` array
files exist locally for this claim, and none were needed — every figure came
from `results.json` or `grid_returns_BTC-USD.csv`.

One deviation from the brief's literal instruction: the "BTC winner curve,
tuning + holdout (to draw)" row asks for a curve built from
`grid_returns_BTC-USD.csv` winner **plus a re-run of that one configuration**.
Re-running the experiment is out of scope (out/ is the only source of
numbers), and the CSV itself holds only the final tune/holdout returns per
config, not a daily equity series. `04_btc_winner_curve.png` therefore plots
the three numbers that do exist (start, end of tuning, end of holdout) as
milestones rather than inventing a daily path shape.
