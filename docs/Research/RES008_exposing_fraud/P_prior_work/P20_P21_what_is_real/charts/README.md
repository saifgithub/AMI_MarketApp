## Notes and deviations from the brief

- The brief's chart-pack table lists six figures to draw: Test A bars, Test B
  dots, Test C bars, the cost pair, sector correlation, and the two-gauge
  card. All six are drawn; nothing was skipped (both source `out/results.json`
  files were present at run time).
- **Test A/B/C figures use only the three pre-registered horizons** (5, 10,
  21 trading days = "next 5 days", "next 10 days", "next 21 days (about a
  month)"), matching `PREREGISTRATION.md` and `RESULTS.md` exactly.
- **Chart 02 (Test B)** rings the one cell that excludes zero — holdout,
  h=21, +1.64% (+0.27% … +3.13%) — and the whole figure carries
  `S.stamp(fig, "ONE CELL EXCLUDES ZERO — RECORDED DEVIATION")` per the
  brief's compliance note ("Do not hide the sixth cell").
- **Chart 04 (cost pair)** carries `S.stamp(fig, "MEAN RETURNS NOT PRECISELY
  ESTIMABLE — NO SHARPE COMPUTED")` since the source explicitly declines to
  compute a Sharpe ratio at this sample size (RESULTS.md, "It is not free,
  and one tail got worse"). The kurtosis panel shows both windows so the
  divergence (holdout rises, definition falls) is visible without implying
  the definition-window improvement generalises.
- **Chart 06 (two-gauge card)** follows the brief's `_dial_frame` convention
  from `C04_win_rate_proves_edge/charts/make_charts.py`: value `v` in
  `[0, 1]` maps to angle `pi * (1 - v)`, so low sits left and high sits
  right on both dials. The "how much" dial spans 1×–3× (holdout h=5 ratio is
  2.08×, comfortably inside); the "which way" dial spans −1.5%…+1.5% (holdout
  h=5 direction difference is +0.44%, with a 95% interval of −0.10%…+0.97%
  that includes zero — the dial shows the point estimate only, and the
  footer says the interval includes zero).
- Colour roles follow `common/ami_style.py`: `S.CYAN` = definition period
  (2005–2018), `S.PURPLE` = holdout period (2019–2026), `S.BENCHMARK` (muted
  grey) = the reference line/placebo (ratio 1.0, difference 0, shuffled
  sizes), `S.MEASURED` (blue) = the two-gauge "how much" dial fill,
  `S.GOOD`/`S.BAD` are used only in the cost-pair chart for
  scaled-vs-constant/shuffled bars, matching the brief's framing that the
  scaled result is worse on the mean and the tail.
- No chart contains a person's name, channel, course, book title, platform
  or vendor. Titles are plain-language, non-advisory statements about risk
  ("After a stressed day, the market moves about twice as much"), never
  imperatives ("size down", "buy", "sell").
- Typography follows the brief: "—" (em dash), "×" for multiples, "−"
  (U+2212) for negative numbers in text, "÷" for ratios; horizons and
  periods are labelled in plain words with years.
