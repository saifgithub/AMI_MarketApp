# C05 chart pack

Generated by `make_charts.py`. Every number is read from `../out/results.json`
or `../out/posthoc_diagnostic.json` at run time; nothing is typed in. The two
claim lines (80%, 99%) are the claim itself, as advertised in
`PREREGISTRATION.md` ("wins 80% of the time alone and 90-99% with the
confirmation") — a named constant, not a measurement, since it is the claim
under test. Run from the RES008 root:

```bash
.venv/bin/python C05_99pct_scalping_recipe/charts/make_charts.py
```

## Notes and caveats

- **Cell labels** are plain words, not version codes: e.g. `V1_loose_60m` reads
  "V1 loose · hourly" (target 1.5x stop, loose filter reading, 60-minute bars).
  `V1`/`V2` = target 1.5x / 2x the stop (`meta.target_r` in `results.json`).
- **Claim lines (80%, 99%) are not measured data.** They come from
  `PREREGISTRATION.md`'s wording of the advertised claim and are drawn as a
  named constant in the script (`CLAIM_LOW_PCT`, `CLAIM_HIGH_PCT`), per the
  brief's allowance for the claim itself.
- **`04_cost_in_r.png`** pools `avg_cost_r` across the four version/filter
  combinations that share a timeframe (e.g. all four `*_daily` cells), weighted
  by `n_trades`, to land on the single per-timeframe figure RESULTS.md §2/§3
  quotes (0.02 / 0.09 / 0.52 R). The placebo half of the bars is
  post-hoc — computed after the pre-registered run, in
  `posthoc_diagnostic.json` — and the figure carries
  `S.stamp(fig, "PLACEBO COST BARS: AFTER THE FACT — NOT PRE-REGISTERED")`.
- **`05_long_vs_short.png`** is entirely post-hoc (RESULTS.md §5) and carries
  `S.stamp(fig, "AFTER THE FACT — NOT PRE-REGISTERED")`. It pools long/short net
  % per trade by trade count across all 7 instruments, for the 8 hourly and
  daily cells only (the brief's beat 7 does not ask for the 5-minute cells
  here, and RESULTS.md §5's by-side table does not report them either).
- Colour roles follow `common/ami_style.py`: amber = the claim as advertised,
  blue = measured, muted grey = benchmark/breakeven/neutral, green/red = good/bad
  or long/short.
- **Not drawn, per the brief's chart-pack table**: the reference figure
  `out/win_rate_vs_claim.png` is redrawn (not copied) as `01_win_rate_vs_claim.png`
  in the AMI style. No other figure from the brief's table was skipped.
- Every pre-registered percentage label is rounded half-up to one decimal via
  `_pct1`, matching RESULTS.md (e.g. 43.59 -> "43.6%").
