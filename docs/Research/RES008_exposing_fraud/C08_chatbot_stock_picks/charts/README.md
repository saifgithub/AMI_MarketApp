## Notes and deviations from the brief's chart-pack table

- **`01_random_portfolio_spread.png` is a bar chart of gap frequencies, not a
  redrawn histogram.** The brief's restyle note says to mark the four video
  gaps on the distribution; `out/random_portfolio_spread.png` (existing,
  reference-only) draws a histogram of one representative window's 10,000 raw
  draws, but those per-draw values are not persisted anywhere in `out/` — only
  percentiles and pooled/per-window summary statistics are. Redrawing a
  histogram shape from percentiles alone would not be numbers read from
  `out/`, so instead this chart shows the four gap frequencies from
  `gap_table.json` directly (pooled over all 236 windows), which is the exact
  data the brief's beat 5 script quotes ("ahead by 13: one in six ... ahead by
  22: one in sixteen"). The within-window median spread (28.1 points) is
  annotated on the same chart. No histogram-shaped figure is included.
- **`02_hindsight_percentiles.png`** redraws the reference PNG's one-dot-per-reply
  layout in AMI style, colouring by model (Opus 5 / Sonnet 5) since Haiku
  refused all 10 "as of 2019" runs and contributes no points. The pooled mean
  and its bootstrap interval are drawn as a vertical line and shaded band
  rather than a legend entry, to keep the 20 dots readable.
- **`03_refusal_grid.png`** is a 3 (model) × 10 (run) grid for the `now`
  prompt only — the prompt read aloud in beat 2 and the one the brief's hook
  and beat sheet build the "19 said no" line from. `picks.csv` also has a
  parallel grid for the `asof2019` prompt (Haiku 10/10 declined, Sonnet and
  Opus 0/10 declined each); that prompt isn't in the brief's chart-pack table
  and isn't drawn separately, but its refusal counts are already the ones
  RESULTS.md §3 reports.
- **`04_pick_frequency.png`** shows the top 7 of the 20 named tickers (all 7
  have counts of 9 or higher out of 11), matching the brief's "top 7 names
  with counts out of 11" instruction. Stamped `TEST INPUT, NOT A
  RECOMMENDATION` per the compliance rule that no ticker may read as advice;
  the subtitle also states the 19-decline context so the 11-of-30 base rate
  is visible on the same chart.
- Colour roles follow `common/ami_style.py`: blue = measured (the model's
  behaviour), muted grey = the one non-claim reference bar (the −8 "behind"
  gap, included for completeness though it isn't part of the claim), amber =
  the compliance stamp only. No claim-coloured (amber) data series appear,
  since this episode's "claim" is a set of prior videos' quoted numbers, not
  a single reference line comparable to a claim threshold.
- All dollar/percent figures are read at run time; `_pct1` (half-up rounding)
  matches the convention used in the C04 pack so labels agree with
  `RESULTS.md`.
