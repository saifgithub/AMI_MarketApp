# CR205

The authoritative summary is this CR's row in
[`docs/forward_planning/cr_list.md`](../cr_list.md) — see `_registry/CR205.row.md`.

Split out of **CR172** on 2026-08-24 (AT:R74). Both splits were deliberate
decisions with reasons recorded on the row, not scope that was quietly dropped:

- **CR204** waits on a dependency that does not exist (full-portfolio greek
  aggregation), and CR172 §9's own text predicted the split.
- **CR205** was offered and explicitly deferred by Saiful, in favour of doing
  lot arithmetic fresh rather than at the end of a long session.

Neither is urgent, and the reason is measured rather than assumed:
`derivatives_allowed` is set on **0 of 42** current mandates, so no user can
reach the option path at all today.
