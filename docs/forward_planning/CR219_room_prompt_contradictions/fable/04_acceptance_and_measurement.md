# 04 — Acceptance criteria (revised) and the trailing measurement

The CR's five criteria survive; restated here for the generated mechanism, with the
decided AC4 timing and the new-field acceptance added.

## Merge-gating criteria

1. **Truth, proven red.** Every availability claim reachable in a composed prompt
   resolves against the rendered sheet: the sync test's bijection holds both ways, and
   the claims guard fails on the two red fixtures — a false denial planted in a
   `## Voice` section (proves the whole-file scan, CR219 acceptance #2 verbatim), and
   a fabricated absent entry with `collision_markers=("Margin trend",)` (proves the
   truth check, acceptance #1 verbatim).
2. **Byte-identity.** The generated block appears exactly once, verbatim, in
   `build_agent_prompt` output for all 12 agents × both surfaces — composition can
   never paraphrase the registry.
3. **Suite green.** `pytest backend/tests/unit/ -q` including the amended
   `test_cr105_*`, `test_prompt_data_parity.py`, `test_config_compose_parity.py`, and
   the CR210 grammar tests (whose `_worst_case_chars` budget check must still pass
   with the grown prompts).
4. **Evidence regenerates.** `evidence/` snapshots rebuilt from the committed scripts
   against the post-change composition (`assemble_room.py` output changes at step 2 of
   the migration); `verify_citations.py` exits 0 against the updated snapshots.
5. **New fields ship honest.** Each free-one field (interest coverage, capex, buyback
   pacing, ATR if confirmed free): renders with CR104 `(LIVE)`/ABSENT provenance,
   has a registry entry (sync test forces this), its former `SHEET_ABSENTS` entry is
   deleted (collision marker forces this), degrade-loudly rules hold, and any
   env-gated setting is forwarded in `docker-compose.yml` per the compose-parity guard.

## Trailing criterion — AC4 (decided: trails, does not gate)

Re-run `citation_rates.py` on post-fix Alpha traffic after **~1–2 weeks** of convenes:

- **Before-arm:** the banked 66-turn corpus (margin trend 24.2%, buybacks 13.3%,
  vs undenied margin structure 95.5%). Already committed; nothing to prepare.
- **Success direction:** margin-trend and buyback citation rates move toward their
  undenied neighbours. No fixed threshold — the honest comparators (Dividend at 16.7%
  undenied) show omission alone suppresses; the claim is movement, not a number.
- **If rates don't move:** that is a **new finding** (the denial was not the binding
  constraint), logged in the CR folder — not a revert.
- **Measure citations, never verdicts.** `pm_self_consistency_samples=1` flips ~19.7%
  of verdicts on redraw; verdict deltas are noise at this n. The arms record already
  enforces this discipline in code — keep it.
- Log the follow-up as a dated section in the CR folder (or a checkpoint-memo note) so
  the trailing check doesn't silently evaporate — the exact failure mode this CR is
  about.

## Exclusions to apply when measuring

Alpha traffic filters per the standing user-report exclusions (CR035 synthetics + seed
rows), and any convene generated by review harnesses (the Gemini arms pattern) stays
out of the production corpus.
