| CR131 | 2026-07-30 | **Instrument the Day Trader preset so it teaches instead of just permitting** — CR129 adds a preset that sets every user risk limit permissive, on Saiful's reasoning that *"if we do not let them fail in a safe environment, they will fail with real money."* Correct, and consistent with CR101's L3 (in a simulation-only trainer the blow-up IS the lesson) — but **a preset that only removes limits is a faster way to lose with nothing learned**, and a user who switches it on, loses steadily and draws no conclusion has had exactly the real-money experience this app exists to replace. The safe environment is only worth something if the user can see what happened to them. **Build:** a measured outcome comparison surfaced to anyone who has run the preset, computed from `sim_trades` and placed beside the published baselines CR129 is already grounded in — Barber & Odean (66,465 households, 1991–1996: most-active **11.4%**/yr vs least-active **18.5%**, market 17.9%, with both cohorts picking stocks about equally well *before costs*, so the entire gap was activity) and Barber/Lee/Liu/Odean Taiwan 1992–2006 (under **1%** reliably profitable, **>80%** losing in a typical half-year, survival **44% / 24% / 15%** at one/two/three years). Minimum metric set: trade frequency while active vs before; realised P&L, annualised only where the window supports it; win rate and average win/loss (the disposition-effect view); **turnover**, so the comparison is like-for-like with Barber–Odean rather than rhetorical; and the user's position on the survival curve. **Rules that make or break it:** never fabricate a comparison from a thin sample — a user three days in has no annualisable return and must be told *"too early to compare"* rather than shown an extrapolation (standing rule: never present an estimate as a measurement); **do not moralise** — the 11.4-vs-18.5 gap is more persuasive than any copy we could write, and a lecture invites the reader to dismiss the data along with it; **it must work for the user who is WINNING**, honestly, including that <1% sustain it and that a short winning window is Barber & Odean's own proposed mechanism for the overconfidence that drives excess trading; and the baselines are US/Taiwan retail equity data, so state that provenance in-surface rather than implying it describes this user's market. **DEPENDS-ON CR129** (no preset to instrument until it exists; the switch event is journalled there). **Read DEF166 first** — clamped closes stamp `realised_pnl` on the full quantity, which corrupts precisely the number this CR reports. Reuse **CR051**'s daily-usage aggregation rather than building a second path.
