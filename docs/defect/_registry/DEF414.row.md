| DEF414 | 2026-09-20 | founder | mobile | **The live Room's Briefing drops a desk's headlines the moment the desk finishes.** Saiful, from a TestFlight screenshot (ASML, phase RESEARCHERS): *"When the room runs the analysts, initially saw the progress and a very short summary. When it moves to the debate, all the summary disappears. The same when it moves from debate to the next. We should keep the summary in display."* Root cause: `_StageRow.build` in `room_briefing.dart` chose the member lines only for `expanded`, `active` or `interrupted` desks; a desk whose every reportable seat has responded is `done`, matched none of them, and fell through to the static subtitle (*"Four independent reads on the same company…"*). So the analysts' four headlines were on screen while the desk was working and replaced by a description of the desk the instant the last analyst reported — and each later desk did the same when the run moved on. CR173 §1 specifies *"one streamed line per stage"* for the whole run, and the row's own comment said a working desk shows the work; a finished desk showing its description is the inverse of that. No test covered a `done` desk: every briefing test used the mid-run state (analysts 2/4, debate not started). Fix: the collapsed member line is shown for every desk that is not `waiting` (one condition, and the now-unused `live` local removed); a desk that has not started still explains itself. Tap-to-expand is unchanged. Regression test `a finished desk keeps its headlines once the next desk starts` builds the 4/4-analysts-reported, debate-running state, asserts all four headlines render and the subtitle does not; verified red with the fix reverted and green with it (12/12 in `room_briefing_test.dart`, `flutter analyze` clean). Not measured: the on-device look with four-plus lines per finished desk — the collapsed line is capped at 2 lines per member, so a fully finished run stacks about a dozen short lines across the four desks; if that reads too long on a phone the lever is per-desk truncation, not restoring the subtitle.
