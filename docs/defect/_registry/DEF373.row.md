| DEF373 | 2026-08-25 | claude | mobile | **Alpaca OAuth: no CSRF nonce, and the WebView would navigate anywhere.** Security review M12. Two independent holes in the one flow that touches a real brokerage account. **(1) No `state` parameter.** `_buildAuthUrl` sent none and `_handleNavigation` exchanged **any** `code` that arrived on `amitrade://alpaca/callback`. An attacker who gets the victim's app to open a crafted callback links the victim's install to the **attacker's** Alpaca account — the victim then trades, and the attacker watches. **(2) No host allowlist**, with `JavaScriptMode.unrestricted`: the delegate returned `NavigationDecision.navigate` for every url, so a redirect off Alpaca rendered attacker-controlled content inside a WebView the user has been told is their broker's login. A phishing surface we built and pointed at ourselves. **The review's cited line range had moved** — `alpaca.py:86-105` is now CR203's device-report route, not an OAuth link — so the backend half no longer exists and only the mobile half was live. Verified before fixing rather than assumed from the review. **Fix:** a per-attempt `Random.secure()` 32-byte nonce (the default `Random()` is predictably seeded, and a guessable nonce is not a nonce), echoed in `state`, **compared before the code is read** so a forged code is never handled, and **single-use** so a replayed callback cannot work twice; plus an https-only registrable-domain allowlist (`alpaca.markets` and subdomains) with everything else blocked **and named in the error**, so a future third-party identity provider fails visibly instead of mysteriously. An unparseable url now defaults to **prevent** — it used to be allowed, and a navigation we cannot inspect is exactly the one to stop. **Guard:** `mobile/test/screens/settings/def373_alpaca_oauth_test.dart` (8 tests), including the `alpaca.markets.evil.com` suffix trick, an http downgrade on an allowed domain, and nonce uniqueness across 200 draws. **4/4 mutations killed.** **Ships on the next store build, not the rsync** — this is client code. | fixed | `mobile/lib/screens/settings/alpaca_connect_screen.dart` | AT:R74 |
