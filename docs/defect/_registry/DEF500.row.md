The app had a banner only for a mid-session stream drop (`roomReconnectingBanner`), none for a cold reattach. **Fix:** new `_RunEventChannel` (event log plus one queue per subscriber, pre-filled with history); `subscribe()` replays the whole run from the first desk then goes live, and yields a leading `reattached` event when someone attached before; `api/room.py` emits it as an SSE `reattached` event; the app parses it (`parseRoomSseEvent`), sets `RoomState.reattached` and shows `roomReattachedBanner` (en/ar/ms) until the run is done.
