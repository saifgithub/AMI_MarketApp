## Design decisions locked this session — do NOT relitigate

1. **Two modes**, user picks the default (persisted, first run = BOARD): a graphical **Verdict Board** and
   a **collapsed transcript** whose rows expand per agent.
2. **Family colour is sacred**, so stance is NOT encoded in hue. **Stance = which of 3 ordinal bands a hex
   sits in. Conviction = a 22×3pt underline bar (length). Identity = a ≤4-char mono label inside the hex.**
   Rejected: opacity/saturation ramp (`hexCyan` clears 4.2:1 only above ~70% alpha, *and* `Opacity(0.35)`
   already means "hasn't spoken yet" at `room_screen.dart:323`); continuous lean axis (asserts precision an
   LLM-sampled stance cannot support); mark size.
3. **The comb holds 11 hexes, not 12** — the PM is the hero tile, captioned `THE PM DECIDES — THIS IS NOT
   A VOTE`. Kills any "consensus %" reading structurally.
4. **Icons ≥44pt, letters ≤32pt.** Same identity at different zoom, never competing schemes. Evidenced: 12
   draft icons read cleanly at 56pt and collapse into blobs at 26pt where letters stay legible.
5. **Panels are rounded rects, not hex-cut.** The DS mount specs `--clip-angle-panel` for cards; **nothing
   in `mobile/lib` implements it**. Hex clipping is only for marks and controls. Hexagonal geometry
   survives on exactly three things: agent marks, the hero's outcome mark, and the BOARD|TRANSCRIPT toggle
   (`cornerCut: 8`, matching `ticker_chart.dart:185`). **The app wins over the mount.**
6. **Tap a comb hex → a bottom sheet, not a mode switch.** The sheet carries `READ THE FULL DEBATE →`
   which switches to Transcript, expands and scrolls to that row. Withheld/empty agents get no jump button.
7. **Per-agent stance comes from a backend structured envelope**, never a client-side keyword heuristic
   (CR038: prompt instructions are not controls).
8. **Ink on any accent fill is `slate900`, never white** — white measures 1.8:1 on `hexAmber`, 2.1:1 on
   `hexGreen`.

## Active constraints / gotchas

**Prototype build — never edit `room_board.html` by hand.** It is GENERATED. Edit
`prototype/template.html`, then `python docs/forward_planning/CR106_room_result_visual_summary/prototype/build.py`.
`build.py` inlines Inter + JetBrains Mono as subsetted base64 woff2 (~35 KB) because an Artifact's CSP
blocks font CDNs. Subsets cache in `prototype/.fonts/` which is **gitignored**.

**Republish to the same URL** by calling Artifact with the same `file_path` in this conversation. From a
fresh conversation, pass `url:` explicitly or it mints a new URL.

**Verification recipe used all session** (headless Chrome + PIL, no browser needed):
```bash
"/Applications/Google Chrome.app/Contents/MacOS/Google Chrome" --headless --disable-gpu --no-sandbox \
  --hide-scrollbars --window-size=1180,1150 --screenshot=out.png --virtual-time-budget=2500 \
  "file:///…/room_board.html"
```
State can be forced by appending `<script>state.X=…;buildControls();render();</script>` to a copy in the
scratchpad. **Chrome exits 0 even on `ERR_FILE_NOT_FOUND`** — check the screenshot, not the exit code.

**Registers are GENERATED (CR081).** Never hand-edit `cr_list.md`. Write
`docs/forward_planning/_registry/CR###.row.md`, then `python scripts/registers/gen_registers.py gen cr`.
**Always pathspec-commit**: `git commit -m "…" -- <files>`. Never bare commit / `-am` / `add -A`.

**Mac is a pure editor** — no backend, no DB, no Docker. Nothing this session needed running.

**Backend gaps that gate CR106 pixels (B1–B3):**
- **B1 `verdict.level_provenance`** — `room_runner.py:859-862` MINTS a missing stop/target at
  `entry*0.94` / `entry*1.13` and discloses it only by appending a sentence to `reason`. **No provenance
  field → no ribbon.** Side effect: every defaulted verdict lands on R:R exactly 2.2:1.
- **B2 per-agent `{stance, conviction, headline}` envelope** — **must land AFTER DEF125** (flat
  `max_tokens=400` truncates the Research Manager mid-sentence in 66.1% of convenes; an envelope adds
  tokens). Must also rebase behind CR098/CR104/CR105, which all edit `room_prompts.py`/`_format_profile`.
- **B3** — `opinions_not_included` and the `agent_withheld` SSE event are emitted server-side and dropped
  client-side.

**Journal replay is a SNAPSHOT, not a `RoomRun`** (`build_journal_entry_for_run`, `room_runner.py:1277`).
No `duration_ms`, no `credit_cost`. An entry written before a field existed will never have it, and
re-fetching `GET /v1/room/{reference_id}` does NOT fix that. The board degrades **per entry**; values are
**never backfilled**.

**Two renderers is the named failure class (DEF098).** Room and Journal must share one widget with two
mappers, or the Journal drifts again — which is exactly how it got worse than the Room.
