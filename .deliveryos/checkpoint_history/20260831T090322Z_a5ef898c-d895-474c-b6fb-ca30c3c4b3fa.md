## Active constraints

  RES folder. This has been respected throughout — verify on resume if adding anything new.
- **Never `git add`/`git commit` a bare `docs/Research` pathspec** — see the footgun above.
  Always name exact files/subfolders.
- **No Sharpe ratio anywhere in this research** — CR136 Rev 2 / Lo 2002 rule (mean returns are
  not precisely estimable at these sample sizes; only second moments are). This is enforced
  throughout RES001; keep enforcing it in any follow-up.

  clustering), so every interval in this research uses a stationary block bootstrap
