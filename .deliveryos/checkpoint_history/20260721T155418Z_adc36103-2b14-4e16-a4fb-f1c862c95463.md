## What was decided this session
1. **4 roles**, per-instance addressing `<role>.<spec>`; instance ID is the routing key on every channel.
2. **Auditor stays the independent gate** (protocol mandates; DEF059 scar tissue). Architect dispatches +
   integrates, **never self-closes**.
3. **Modularity measured** (import-graph grep): api/room split is real (asymmetric producer/consumer;
   24/42 services import zero others). Hot files: `db/models.py`→`coder.api` sole schema owner;
   `safety_floor.py` serialized api↔room; backend↔mobile = hand-mirrored JSON contract (mobile must
   re-verify `fromJson` vs real backend JSON).
4. **Context mgmt (verified):** `/compact` is NOT automatable (agents can't run slash commands) and NOT
   needed — auto-compaction is always-on backstop (~1M, expensive → avoid). Instances are **short-lived
   per-lane**, continuity in files, respawn fresh. Token economy = bound lifetime to a work-unit.
5. **Consolidation:** unified 3 folders → one `orchestration/` root (dispatch/ + audit/ + history/).
6. **Ledger retention:** timestamped rows; `rotate_trail.py` (ledger-agnostic) rolls rows older than
   **`--keep-days 4`** into monthly `history/trail/`. **SINGLE shared Architect job — NOT per-agent.**
   `audit-trail.md` rotated the same way by the **Auditor** (its domain → `audit/trail/`, gap-fill 6).
7. **Hosting VERIFIED empirically** (claude v2.1.145): an agent's shell **CAN** launch a headless worker
   `claude -p --session-id <uuid> --permission-mode acceptEdits` (fresh, cheap ~6/10 tok overhead,
   persisted), and `claude --resume <uuid>` restores full context. It **CANNOT** dispatch the
   live-attach `claude agents` kind (needs a TTY). BINDINGS documents 3 models: **A) local headless
   workers [RECOMMENDED]**, B) interactive `claude agents` (human-launched), C) cloud routines (fire via
   API). `live_handle` = the current run's UUID.
