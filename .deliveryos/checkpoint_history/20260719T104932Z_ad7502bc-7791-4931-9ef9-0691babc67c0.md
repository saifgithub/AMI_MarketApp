## Active constraints / gotchas

- **`backend/.venv/bin/python` is required for pytest** — system python3 has no
  `structlog`. `cd backend && .venv/bin/python -m pytest tests/unit/ -q`. Full suite
  takes ~115s, so it exceeds the 120s Bash default — redirect to a file and echo `$?`.
- **Read pytest's OWN exit code, not the background-wrapper's.** I reported "suite
  passed" once on the wrapper's exit 0 while pytest actually had 5 failures. Burned.
- **Ordering constraint is enforced in code:** `scripts/shuffle_quiz_answers.py`
  hard-refuses to run if any explanation still cites an option by index. DEF065 must
  precede any re-shuffle.
- **The shuffle's load-bearing invariant:** `options[answer_index]` TEXT must be
  byte-identical before/after — only position may move. Verified 0 changed across all
  754 questions.
- **CR042's shipped state came from TWO script runs.** First implementation re-drew
  until the answer MOVED off its slot, which inverted the tell (index 1 → 1.1% on
  challenges, effectively 3-option questions). Changed to uniform targeting and re-ran.
  This is documented honestly in the CR doc — do not "fix" it by claiming single-run
  reproducibility.
- **Daily-challenge JSON must be rewritten TEXTUALLY, not via `json.dumps`** — a
  re-dump expands the inline `"tags": [...]` arrays and buries the change under ~280
  lines of noise per file.
- **`281_what_is_a_market__q1` is excluded from the shuffle** — the corpus's only
  2-option (True/False) question.
- **Guard:** `backend/tests/unit/test_lesson_corpus_integrity.py`. Verified red against
  the real defect BEFORE the fix (4 assertions failed naming all 12 files), and red
  again on 3 injected regressions after. It deliberately does NOT assert a distribution
  — a uniformity test would go red on legitimate content edits.
- **Filed as failure pattern P3** in `docs/initial_specs/08_tech/failure_patterns.md` —
  "Content validated by exemplar, never as a corpus". All 16 prior lesson tests pinned
  to `283_market_order_vs_limit`, which is why this survived months.
- **Tests must derive answers from parsed content**, never hardcode. 8 sites in
  `test_lessons_service.py` used `answers=[1, 1]`; all now use
  `_correct_answers(svc, lesson_id)` / `_wrong_answers(...)`.
- **Alpha is in the NON-ablated baseline state** — `SUPPRESS_ANALYST_CONSENSUS=false`
  on both Mac `infra/alpha.env` and melehost `.env`. CR035's baseline arm finished
  (results stopped writing 12:20 on 2026-07-18).
- **Concurrent API fetches get 403'd by Cloudflare.** 8-thread urllib triggered it;
