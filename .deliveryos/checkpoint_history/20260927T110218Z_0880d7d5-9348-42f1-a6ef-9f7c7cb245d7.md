  correction) — continue the same discipline for any further row-file edits.
- **Degrade loudly (CR040)**: any field that can't be resolved (no CIK
  match, rate limited, no S-1/13D/13G on file) must render an explicit,
  honest state — never silently blank or fabricated. Baked into CR244's
  acceptance criteria already.
- **Prompt instructions are not controls (CR038)**: ~70% failure rate on
  prompt-only behavioral guardrails — this is WHY the 10b5-1 plan-type tag
  must be structural (extraction-layer fact), not just persona wording.
  Don't relax this if build pressure suggests skipping the structural tag
  as a shortcut.

  `backend/app/services/room_prompts.py:2175-2183`): fundamentals_analyst,
  market_analyst, news_analyst, social_media_analyst. The other 8
  (bull/bear researchers, research_manager, trader, portfolio_manager, 3
  risk debators) are full-sheet by default (`_ALL_DOMAINS`) — any new lane
  tag reaches all 8 automatically, no selective exclusion mechanism exists.
  This is load-bearing for how Part 2's insider-trade routing actually
  behaves at runtime — don't assume "routed to Bull/Bear" means ONLY
  Bull/Bear see it.
- **The established 5-point pattern** for adding any new EDGAR feed (from
  CR221's 8-K work, this CR's own template): extraction module → DB table +
  ingest script → `field_state` key → lane-gated header disclosure bullet
  → lane-gated body line → persona-file sentence per affected agent, plus
  updates to the two existing anti-fabrication test guards
  (`backend/tests/unit/test_agent_prompts.py:61`,
