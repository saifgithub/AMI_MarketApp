```

  --allowedTools "Bash Edit Write Read Grep Glob TodoWrite" \

  --session-id <FRESH-uuid> \

```
Run via Bash tool with **run_in_background: true**. Non-obvious gotchas, each learned the hard way:
- **Command MUST start with `claude -p`** → matches the `Bash(claude -p *)` allow rule Saiful added to
  `.claude/settings.local.json` → bypasses the auto-mode classifier. (Saiful had to add that rule; I
  cannot edit settings to self-grant — classifier blocks it.)
- **NO output redirect** (`> log 2>&1`) — a redirect makes it a *compound* command, the simple-command
  allow-rule stops matching, and the classifier blocks it. The background buffer captures output anyway.
- **NO `--dangerously-skip-permissions`** — the classifier hard-blocks that flag categorically,
  regardless of allow rules. Saiful: "use auto mode, not a full bypass." Scoped `--allowedTools` is enough.
- **`--session-id <uuid>` must sit RIGHT BEFORE the prompt** — `--add-dir` is variadic and will swallow
  the prompt as a 2nd "directory" if the prompt follows it (silent: empty output, no session created).
- **Lead the prompt with `AMI-TRADE · <instance> · <lane>`** so the session title in Saiful's list is
  readable (else it's the whole prompt dump — he flagged this).
- Each worker prompt tells it: claim → build own paths only → self-test → write audit lane (code) or
  set READY_FOR_REVIEW (content) → commit own paths BY NAME + **`git pull --rebase --autostash origin
  main`** before push → set STATUS → STOP. Disjoint paths + autostash = concurrent pushes never collide.
