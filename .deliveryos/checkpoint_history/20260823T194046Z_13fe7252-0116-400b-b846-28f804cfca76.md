## 3. THE GATE — read before turning anything on

**`SimPortfolio` (Dart) has no `options` field.** The backend `Portfolio` schema DOES carry
`options: list[OptionLeg]` and `sim_engine.py:547` populates it. So today a user could consent to
a structure and then **not see it anywhere in their portfolio list**.

**Not live-exposed, and this was measured on Alpha 2026-08-23:**
```
select count(*) filter (where snapshot->'compliance'->>'derivatives_allowed' = 'true'),
       count(*) from mandates where is_current;   -->  0 | 42
```
The option menu is gated on `mandate.compliance.derivatives_allowed` (NOT on
`PM_OPTION_LADDER_ENABLED`, which only controls a PM-prompt block and is correctly off while
CR201 owns that window). **Zero of 42 current mandates permit derivatives, so nobody can reach
the CTA.** That is the safety margin — the portfolio option card must land before any mandate
sets that flag.

**NAV is fine and was checked, not assumed:** `Portfolio.total_value` carries an unmarked leg at
`avg_premium` (`schemas/trade.py:128-151`), so opening is value-neutral — no phantom loss. What
is missing is P&L *movement*, which is exactly what lesson 322 needs a user to watch.
