## Active constraints / gotchas

- **`git commit -- <paths> -m "msg"` FAILS** — after `--`, git reads `-m` as a pathspec. Put `-m`/`-F`
  BEFORE `--`. (Bit me this session; recovered by writing the message to a file and using `-F`.)
- **`git add <path>` also commits whatever is ALREADY staged.** Prefer `git commit -F msg -- <paths>`
  when the tree holds other tracks' work.
- **zsh does NOT word-split unquoted vars** — `grep pat $FILELIST` passes one giant filename and
  "succeeds" misleadingly. Use `$(cat file)` or an explicit loop. (Produced three false CLEAN
  results this session before I caught it.)
- **`xargs -a` is not supported on macOS** (BSD xargs). Use `$(cat file)`.
- **Foreground `sleep` is blocked** by the harness; a bare `for` busy-loop returns instantly. To poll,
  use `python3 -c "...time.sleep(5)..."` or the Monitor tool.
- **Mac is a pure editor** — no backend/DB/Docker. Worktrees have **no venv** — always use the
  absolute `.venv/bin/python` path.
- **Piping a long build through `| tail -N` hides all progress** (pipe buffers until exit) — redirect
  to a log and poll.
- `/promote-to-alpha` rsync MUST keep `--exclude='audit/' --exclude='reports/'` (DEF081); run the
  rsync as its **OWN** Bash call. `.env` ships only via `scp infra/alpha.env melehost:~/ami_trade/.env`.
- **Provenance INTERNAL-ONLY** (CR060 §18). **AMI by name**, never "the AI". DEF069: ARB
  `use-escaping` off ⇒ single `'`. **Religious/legal rulings → the stakeholder/SME, never an agent lane.**
- Version/build bumps are governance-**EXEMPT** (plain `(AT:R<N>)`). Everything else needs CR/DEF.
