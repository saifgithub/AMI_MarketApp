## Gotcha that bit me this session (do not repeat)

A multi-line shell variable holding a file list collapsed into ONE filename, so
`grep … $TIER_A` scanned **zero files and printed "(clean)"** — a false negative I nearly
reported as a verified result. Caught it via ugrep's "No such file or directory" warning. **Use
`set -- f1 f2 …` then `"$@"`**, and always echo the file count (`scanned: $# files`) before
trusting a clean grep.
