## CR120 decisions locked — do NOT relitigate

1. **Segmented tabs.** Three hex segments (`cornerCut: 8`, matching `ticker_chart.dart:185`) under a
   pinned compact value card. Fill flip only — **no sliding indicator, no swipe-between-tabs** (DS
   forbids motion on text; a horizontal swipe inside a bottom-nav tab fights the OS back gesture).
   I recommended the bounded dashboard and Saiful chose tabs; the mitigations below are the deal.
2. **POSITIONS carries holdings AND open trades. HISTORY is closed-only**, count reads `195` not
   `200`. An open trade is money at risk with a live stop — it must not sit behind a tab you don't
   land on. This also dissolves the interleave defect (no list contains both statuses).
3. **Closed trades cap at 25, span described** — `LAST 25 CLOSED · 17 MAY – 28 JUL`. The period is
   **described, never used to filter** (a period filter empties for an inactive user and unbounds for
   a day-trader; a combination must pick union or intersection). **Open trades are never capped.**
4. **The summary strip is computed over ALL closed trades** and captioned `ACROSS ALL 195 CLOSED`.
   A hit rate over a display window is a wrong number wearing the authority of a statistic.
5. **Tab state is `TabController` state, never persisted.** `IndexedStack` at
   `home_shell.dart:42` keeps `PortfolioScreen`'s State alive for the app session → push/pop and
   bottom-nav round trips preserve the tab; a relaunch lands on Positions. **Doing nothing is the
   whole implementation.** Persisting across launches is rejected (armed stop behind an unseen tab);
   a staleness rule is rejected (a tab that sometimes remembers is worse than either rule).
6. **Live pip on POSITIONS when an open trade exists** — 6pt flat-top hex, **family cyan not amber**
   (an open position is a state, not a warning), `textHigh` when active. Its count is holdings, so
   the tab otherwise under-reports its own contents; a second number would conflate two things and
   tab labels have no width to spare.
7. **The client branches on `retention_days`, NEVER on plan.** The Journal response already carries
   it, `journal.dart:141` already parses it into `JournalState.retentionDays`, and
   `journal_screen.dart:113-120` already renders an amber notice from it — so CR120 **extends a
   shipped disclosure**, not a new pattern (reinventing = DEF098 two-renderer class). `null` =
   unlimited. **Never hardcode 30 in the app.**
8. **Fail-safe:** `retention_days` only reaches the client on the *journal* list response, which the
   Portfolio never calls. If unknown → show the caveat **without a number**, never the reassuring
   branch. B3 removes the guess.
9. **A list over 12 items gets search + sort inside its own tab.** Per-list defaults: holdings by
   value, watchlist **A–Z** (a watchlist is scanned to *find* a name; movers-first moves it daily),
   closed newest.
10. **Sector donut moves inside Positions**, where it describes the list beneath it.

## Active constraints / gotchas

**Prototypes are GENERATED — never hand-edit `portfolio.html` or `room_board.html`.** Edit
`prototype/template.html`, then
`python docs/forward_planning/CR120_portfolio_list_structure/prototype/build.py`
(CR106 has its own). `build.py` inlines Inter + JetBrains Mono as subsetted base64 woff2 because an
Artifact's CSP blocks font CDNs. Subsets cache in `prototype/.fonts/`, gitignored via the generic
`docs/forward_planning/*/prototype/.fonts/` pattern added this session.

**Glyphs must be in `build.py`'s `UNICODES` or they silently vanish.** Inter has no U+25BE/U+25B8 —
a sans caret fell back to a full stop. Anything triangular must carry the mono class AND the
codepoint.

**Republish keeps the URL** by calling Artifact with the same `file_path` in the same conversation.
From a fresh conversation, pass `url:` explicitly or it mints a new one.

**Headless-Chrome verification recipe** (used all session):
```bash
"/Applications/Google Chrome.app/Contents/MacOS/Google Chrome" --headless --disable-gpu \
  --no-sandbox --hide-scrollbars --window-size=390,844 --screenshot=out.png \
  --virtual-time-budget=2500 "file:///…/portfolio.html"
```
Force state by appending `<script>state.X=…;buildControls();render();</script>` to a scratchpad copy.
**Chrome exits 0 even on `ERR_FILE_NOT_FOUND`** — verify the screenshot, not the exit code.
**`--window-size` is not the layout width** — headless laid out at 500px when asked for 400, which
shifted the device and looked like a clipping bug. Pin `body{width:390px}` / `.wrap{max-width:390px}`
in the harness, and for RTL set `dir` on `#screen` only, not `documentElement`, or the harness itself
shifts the device off-frame.

**Measure, don't estimate.** The prototype reports `scrollHeight/clientHeight` + row count live under
the phone. Every number above came from there.

**Registers are GENERATED (CR081).** Never hand-edit `cr_list.md`. Write
`docs/forward_planning/_registry/CR###.row.md`, then
`python scripts/registers/gen_registers.py gen cr`. **Always pathspec-commit**:
`git commit -m "…" -- <files>`. Never bare / `-am` / `add -A` — other tracks leave the shared tree
dirty constantly.

**Shared checkout.** HEAD is usually another track's commit. Architect is the sole ID minter; I took
CR120 because 106–108 set that precedent in-session, but **check `ls docs/forward_planning/_registry/`
for the max before minting** — it went 108 → 119 in one day.

**Mac is a pure editor** — no backend, no DB, no Docker. Nothing this session needed running.
