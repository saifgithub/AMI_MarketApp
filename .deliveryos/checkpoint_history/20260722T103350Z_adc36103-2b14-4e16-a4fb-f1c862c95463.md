## DEF082 — the build spec (design is SETTLED, colours APPROVED)

**Defect:** `mobile/lib/screens/lessons/lessons_screen.dart` builds the group cluster from a hardcoded
7-entry `origins` Offset map and **iterates that map**, using the API response only as a filter:
```dart
for (final entry in origins.entries)      // hardcoded 7
  if (trackMap.containsKey(entry.key))    // API only filters
```
Any backend track without a hardcoded position is **silently dropped**. `_trackColor` / `_trackLabel` are
7-entry too. `TrackLessonsScreen` is constructed at exactly **one** call site (`lessons_screen.dart:153`)
from `onTrackTap`, so there is **no alternate entry point**.
