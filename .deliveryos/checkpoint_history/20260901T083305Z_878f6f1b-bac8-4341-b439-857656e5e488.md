(a) the first cut answered "full suite required" for ANY non-Python change, which is
useless in practice — every real working tree here has untracked memos, so it always

LITERAL STRING CONSTANTS the tests themselves contain (derived, not a hand-written glob

that test names the file. (b) first version of that matching used bare path segments, so
the word "mobile" in 15 unrelated tests attributed every `Podfile.lock` change to all of
them — tightened to exact path/basename/multi-segment-suffix only.

selector searches, so the test named the very file it asserted was unnamed, inverting the
assertion. Fixed by deriving the example from `git ls-files` at runtime. New
