## The dark launch (Amendment F)

The game ships inside the normal app, reached ONLY by **long-pressing the Floor
footer** (`⬢ AMI TRADE • EDUCATIONAL SIMULATION`). Gate is
`kGamesEnabled = bool.fromEnvironment('AMI_GAMES')` in
`mobile/lib/features/games/games_gate.dart`, guarding a const-conditional entry in
`mobile/lib/app.dart`'s `routes:` map.

**`bool.fromEnvironment` accepts ONLY the literal strings "true"/"false".** Passing
`AMI_GAMES=1` silently compiles to the default `false` — it built and installed a
game-less APK while every step reported success. `install_android.sh` now VERIFIES
THE ARTEFACT after each build (extracts `libapp.so`, greps for a games-only string,
**with a control string** so the check cannot silently degrade into one that always
passes). `install_iphone.sh` has no equivalent guard yet.

Saiful's ruling (AT:R66): the game ships in store builds too — *"if anyone 'finds'
it, it will be an easter egg for them."* Safe only because both paths are
structurally confined to unreviewed, team-only tracks: Play is pinned to `internal`,
and `test_…` RevenueCat keys force `--internal-only` on TestFlight (internal groups
skip Beta App Review). Both scripts print a banner saying DO NOT promote onward.

  isolate the risky half (shared users/AMI Cash/Postgres). Recorded as CR109

  *"why bother? so long as no one can reach it, the additional control adds
  complication with no upside."* Correct. But `main.py` serves `/docs` +
  `/openapi.json` on non-prod, so the games router registers
  **`include_in_schema=False`** or the whole API is published while meant to be dark.
- **Real ledger from day 1** — *"we will need history anyway, and we can always clean
  the data."* No `is_internal` column. `career_events.field_id`/`entry_id` are
  **NOT NULL** so cleanup is a field-scoped delete.
- **CR133 no longer blocks CR109** — the hidden route is the temporary home §13.1
  said the game would otherwise lack.
- **`/trade` takes SHARES, `/trade/quote` takes shares OR dollars.** Deliberately
  asymmetric: outside market hours the order queues and `submit_trade` never touches
  `current_price` — pricing a queued order at queue time IS the stale-price hindsight
  exploit §5.1 exists to prevent. The client quotes in dollars, then places the share
  count the quote returned.

# Active constraints

- **THE RECURRING BUG CLASS — read this before writing any client model.** SIX
  client/server contract defects were found in one evening by USING the app, none by
  either suite. Every one was a client field name that never matched the wire, read
  null-safely, defaulting silently:
  | client read | wire actually sends | damage |
  |---|---|---|
  | envelope `data['runs']` | bare JSON array | threw on a 200; "Couldn't load your game runs" |
  | `next_field` nested | flat `field_id`/`state`/`deadline`/`already_held` | entry card with no deadline |
  | `cash` | `current_cash` | **every order sized as % of ZERO** |
  | `shares`, `est_fee` | `quantity`, `estimated_fee` | confirm card showed 0 shares, $0.00 fee |
  | `status` (absent) → default `'filled'` | `queued`/`filled` booleans | **claimed a fill that never happened** |
  | `stake` | `total_value` | wrong book size |
  **Root cause: the lane briefs specified FIELDS and never SHAPES or key names**, so
  each lane unit-tested against its own reading and both stayed green.
  `mobile/test/models/games_wire_contract_test.dart` now pins payloads VERBATIM from
  live Alpha responses with real-value assertions. **Any new endpoint: curl it, paste
  the real payload into that file, assert real values — not "parses without throwing",
  which would have passed on all six.**
- **Never default to the affirmative.** `status ?? 'filled'` told a player their order
  executed when the market was shut. Unknown must render as unknown (now `'unknown'`,
  amber banner, third state).
- **§7.1 fence:** no `skip_compliance`-shaped argument anywhere.
  `SimEngine._execute_fill()` never consults compliance; `submit()` runs the floor,
  `submit_game_trade()` takes no `mandate` at all.
  `backend/tests/unit/test_cr109_trade_path_split.py` guards it, including that
  `submit()` STILL calls the floor.
- **Do not price a queued order at queue time.** Computing committed cash at READ time
  is fine (display estimate, never stored, never fills).
- `quantity`/`notional` are `Field(gt=0)` — a zero-share order silently queued five
  no-ops before this.
- **Shared checkout, other tracks live.** Pathspec commits only:
  `git commit -m "…" -- <paths>`. Stage new files by explicit path. Never `-am`/`add -A`.
- **Never run another lane's tooling.** `scripts/i18n_coverage_report.py` REWROTE 8
  tracked content files despite its name; it is now read-only by default (`--write` to
  apply) and the class is filed as **failure_patterns P17**.
- Test runner: `cd backend && uv run pytest tests/unit -q`. Full suite ~6min — run it
  backgrounded. There is **no `timeout` command** on this Mac.
- Postgres on melehost: `docker compose exec -T postgres psql -U postgres -d ami_trade`
  (user is `postgres`, NOT `ami`).
