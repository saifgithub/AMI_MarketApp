## The two real findings this session

### 1. The routine's list-builder was silently dropping items — FIXED

`.claude/commands/daily-cr-def-review.md` step 3 read the Status column by **fixed field
index** (`$5` for CRs, `$7` for Defects). That shifts on any row whose narrative text
contains a `|` — measured: 5 DEF rows and 4 CR rows do.

Consequences on the 07-28 run: DEF102 + DEF136 wrongly listed as `open` (a title
fragment contained the word "open"), and **CR106 + CR109 silently missed** despite being
genuinely `proposed`. A false positive costs one question; a silent miss means an item
never gets asked and nobody notices — the exact failure CR085 exists to prevent.

**Fix (in `df89527`):** index from the END of the row. Both schemas put Status
4th-from-last, so `awk -F'|' '{print $(NF-3)}'` works for both registers. The command doc
now carries the runnable loops plus the *why*. Verify with:
`git show HEAD:.claude/commands/daily-cr-def-review.md | grep -c 'NF-3'` → 3.

### 2. The shared checkout moves underneath a long review — handled, keep handling it

Other tracks committed to `main` **while the questions were being asked**: DEF136 fixed +
submitted to audit (`7d35466`, `88f6926`), DEF137's translation half landed (`7751ff5`,
28 keys not the 24 its row claimed), CR109 filed (`2256e1b`), build bumped to `0.1.0+56`
(`4f9dbfb`). The opening `git pull` said "Already up to date" and was stale within the
