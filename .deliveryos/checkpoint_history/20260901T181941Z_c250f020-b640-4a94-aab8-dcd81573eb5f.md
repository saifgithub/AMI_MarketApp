## What was decided this session (CR214 half, before the pivot)

- **Root cause of every prior "no edge found" result**: latency budgets and outage fail-safes
  were letting provider failures masquerade as Room decisions. Before tonight's fixes, 12 of 14
  CR214 convenes were DEF059 fail-safe PASSes, not real verdicts.
- **DEF389** (fixed, promoted): the 60s httpx transport timeout sat *inside* the 90s
  orchestration guard meant to backstop it, so the guard was unreachable and failures logged as
  a blank `error=""` (`httpx.ReadTimeout().__str__()` is empty).
- **DEF390** (fixed, promoted): the 90s orchestration guard itself,
  `room_runner._AGENT_LLM_TIMEOUT_S`, was a hardcoded module constant that CR211's model swap
  outgrew. Sized the replacement (180s) from real `llm_audit` data: 290 portfolio_manager calls,
  mean 42.4s, mode 35-40s, 21 calls piled in the 90-95s bucket (clipping, not a mode).
- **DEF388** (fixed, promoted): the rank-IC estimator scored on raw `approve_votes` instead of
  `approve_votes / samples`, so a provider that returned fewer draws than configured (1-of-1 vs
  3-of-5) ranked backwards — demonstrated as a sign flip (-0.5 vs +1.0 IC on identical rows).
- **DEF387** (fixed, promoted): `backtest_sweep.py` now refuses an unsupervised launch via an
  `AMI_SWEEP_SUPERVISOR` env marker (not a process-ancestry check — deliberately, since the
  supervisor runs on the host and the sweep runs in-container, so ancestry would refuse every
  legitimate run and admit every bare one). Supervisor scripts moved into version control at
  `backend/scripts/supervisors/` (were melehost-only, rsync-excluded, one disk away from gone).
- **CR214 live-panel correction**: `weekly_room_retro.py`'s `scored_*.jsonl` is **cumulative**,
  not incremental — pooling every weekly file double-counts (W34's 141 runs are a strict subset
  of W35's 162). Corrected panel: **162 runs / 28 dates**, not 303/46. The previously-cited live
  corroboration (+1.19% at 4w) rests on only 4 paired dates; the placebo arm (12 dates, RES001's
  mandated comparison) gives +0.30%. The live panel does **not** corroborate the backtest
  headline as strongly as earlier stated in this session.
- **Headline backtest finding stands, untouched by any of tonight's fixes** (it re-scores
  already-banked, 0%-outage Phase B runs): within-date paired spread at the Room's own ~13-week
  (62 trading day) horizon = **+5.09%**, CI −1.41…+12.88, 16 dates. Not significant, but
  pre-registered and 3.5× the 4-week figure. File:
  `docs/forward_planning/CR214_room_edge_test/FINDING_2026-08-31_horizon.md`.
