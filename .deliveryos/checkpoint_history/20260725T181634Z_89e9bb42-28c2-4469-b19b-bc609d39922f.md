- **Saiful's "limit number of agents during a Room convening" idea is NOT locked — genuinely
  open design space.** No existing axis limits *which/how many* of the 12 agents participate in
  a convene. The two adjacent existing axes are different things: **axis #3 "Full Rooms/month"**
  (`paywall_axes.md:13`) already gates Room *frequency* (1 free/month + credits vs 10/20
  included) — this is what CR047's Winzip funnel softens. **Axis #5 "Debate rounds in Room"**
  (`paywall_axes.md:15`) gates *debate depth* (1 round for Floor Pass/Trader, up to 3 for Floor
  Manager) — not agent count. A new "fewer agents for free tier" axis would be net-new.
  **Tension to flag, not resolve:** CR036's locked messaging pillar (`CR036_go_to_market_plan.md`

  instead of 1 chart tool."* If the free tier's Room convene doesn't actually run all 12 agents,
  that claim needs scoping (paid-tier-only promise vs a "12 exist, free tier samples N" framing)
  — worth surfacing as a design constraint, not a blocker.
- **Free-tier honesty commitments** (`paywall_axes.md:47-61`) — a Floor Pass user must be able
  to: learn anything in the curriculum, complete all 12 Agent Academy modules, use all 12
  agents (after Earn Path), run ≥1 Room/month, run ≥5 1-on-1s/month, edit mandate freely, view
  30-day Journal, use daily challenges/streaks. Framing: *"friction is operations volume + ads +
  caps on power features. Not access."* — any new limiting idea should be checked against this
  frame (is it a volume cap, which is fine, or an access cap on something already promised,
  which needs Saiful to consciously override the doc).
