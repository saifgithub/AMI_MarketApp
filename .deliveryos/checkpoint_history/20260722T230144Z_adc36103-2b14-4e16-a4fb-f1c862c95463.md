## Active constraints / gotchas
- **`git add <path>` also commits whatever is ALREADY staged.** It bit me: pre-staged `legal/`
  renames got swept into my bump commit. Fix used: `git reset --soft HEAD~1`, `git restore --staged`,
  then **`git commit -- <pathspec>`** (explicit pathspec = only that file). Prefer the pathspec form
  whenever the tree has other people's work in it.
- **Piping a background build through `| tail -N` hides ALL interim progress** (pipeline buffers
  until exit) — for long builds, redirect to a log with `nohup … > LOG 2>&1 &` and poll the log.
- **`git rev-parse … origin/main` can transiently fail** with `fatal: Needed a single revision`
  right after a fetch. Just retry; the ref is fine.
- **Mac is a pure editor** — no backend/DB/Docker. Unit tests only:
