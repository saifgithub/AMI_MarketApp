## Design note (disclosed)

The streak chip's **amber/green "today filled"** is scoped to **today's daily challenge**
(`myAttempt != null`), not every streak-eligible activity (lessons/journal also feed the
backend streak). This is a deliberate mobile-only simplification — the backend `/me` does
not expose a `today_filled` flag, and the chip's job is to nudge the daily challenge. The
streak *count* is exact (from `/me`); only the colour cue is challenge-scoped. A precise
`today_filled` backend field is a possible follow-up if desired.
