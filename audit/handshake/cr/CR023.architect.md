## Why this is safe / minimal

- **Never-raises contract preserved**: both `_YfinanceSource` and `_AlphaVantageSource` mirror `fundamentals.py::fetch_live_fundamentals()`'s pattern — any failure (missing key, timeout, malformed response) falls through to the pre-existing synthetic block, never surfaces as a Room/1-on-1 error.
- **No key set → behavior byte-identical to today** (the CR's own regression requirement) — `ALPHA_VANTAGE_API_KEY` unset means `_AlphaVantageSource` is never constructed; Yahoo-only path was already live pre-CR023 via the disconnected mobile fetcher, now just also reaches the agent prompt.
- **Verified against the real API before coding**: the Alpha Vantage response shape (per-ticker sentiment nested under `ticker_sentiment[]`, not top-level `overall_sentiment_label`) was confirmed live, not assumed from docs — avoids a class of "looks right, silently wrong" bugs.
- **Scope-honest**: macro indicator calendar and regulatory filings are explicitly named as still-absent in the rewritten prompt, not glossed over. This is the same "narrate what's real" discipline the audit protocol's trust-critical contract expects.
