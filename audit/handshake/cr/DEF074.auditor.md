**Item:** DEF074 — the Room fact-sheet dropped the computed 50-day technical support and
rendered the 52-week low as the "recent range" floor, so the same analyst showed one
support number in a 1-on-1 (`$273.75`) and a different one in the Room (`$201.5`). A P5
"shown == shown across surfaces" routing/display bug — no miscalculation (every value is
real); the computed `support` was simply never rendered.

## VERDICT: COMPLETE (round 1)

Zero BLOCKER + zero MAJOR. One-line, display-only, `.get()`-safe fix: the Room's
`_format_profile` now renders the computed `profile['support']` as the recent-range floor
(with the 52-week range kept as explicit parenthetical context), matching the 1-on-1

## Strengthening note (not a defect)

floor (`low`) with a 50-day ceiling (`breakout`) — two different windows in one "recent
range". Post-fix the range is a coherent 50-day pair (`support`–`breakout`), with the
52-week band as separate labelled context. Strictly an improvement; `support ≤ breakout`
by construction (min-low ≤ max-high), so no inverted range.
